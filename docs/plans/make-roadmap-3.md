# Make — roadmap 3 (после roadmap-2)

Статусы: ✅ сделано · ⏸ ждёт внешнего ресурса · ✗ пропущено (причина в строке).
Порядок — по номерам. Правила прогона те же, что в roadmap-2 (гейт на пункт, проверка на стенде :8799, KB + коммит, релиз каждые 5 пунктов).

| № | Пункт | Статус |
|---|---|---|
| 1 | Release Center: проверка свободного места перед сборкой/деплоем (< 5 ГБ — предупреждение, шаг падает явно, а не молча висит на health-check) и `docker builder prune` старого кэша перед сборкой | ✅ `RELEASE_MIN_FREE_KB` 5 ГБ: df → prune (until=24h + image prune) → явный fail шага «Сборка» |

| 3 | Аналитика публикаций: просмотры по дням и рефереры в `.publish.json`, график в диалоге публикации | |
| 4 | Мобильный Make: панель комментариев как нижняя шторка, жесты инспектора (тап = выбрать элемент) | |
| 5 | Скриншоты превью: web-шрифты и `@import` в клоне html2canvas (инлайн шрифтов через FontFace/`document.fonts`) | |
| 6 | Совместный доступ для участников проекта ChatAI: роли «редактор/зритель» для Make-чата внутри проекта (поверх read-only ссылки) | |
