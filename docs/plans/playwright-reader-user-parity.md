# Playwright Reader: работа как у пользователя

Двадцать кругов улучшений с одной мерой: **модель в чате и в канбане должна
пользоваться браузером так же, как человек, а человек — работать с панелью и на
компьютере, и на телефоне.** Каждый круг — десять улучшений для модели и десять
для интерфейса, свой коммит, свой гейт.

Проверяется вживую на локальной сборке поверх прода: UI, playwright-reader,
web-reader, make и browser-runner идут из этого чекаута, а база, CLI и раны
остаются продовыми (`/private/tmp/voicechat-local-reader/launch.py`).

## Круг 1 — клавиатура, фокус и буфер обмена; кадр на любом экране

**Модель.** Умела кликать и печатать, но не умела дойти до элемента табом,
нажать сочетание и работать с выделением — то есть не умела ровно того, чем
человек пользуется постоянно.

- [x] `hotkey` — сочетание с удерживаемыми модификаторами (ctrl+a, meta+c, shift+Tab);
      модификаторы отпускаются даже при ошибке нажатия.
- [x] `press` c `repeat` — удержание клавиши (ArrowDown до нужной строки) одним вызовом.
- [x] `focus` — фокус на элемент без клика: клик по пункту меню и переход на него
      фокусом дают разные события, и ошибки доступности живут в этой разнице.
- [x] `focused` — что сейчас в фокусе: селектор, роль, значение, видимое кольцо
      фокуса, признак «внутри диалога» (ловушка фокуса в модальном окне).
- [x] `focus-order` — порядок обхода по Tab целиком, с положительным tabindex впереди.
- [x] `clear` — очистить поле, как Ctrl+A → Delete, с событиями input/change.
- [x] `select-text` — выделить текст элемента или страницы.
- [x] `copy` — прочитать выделение, включая выделение внутри поля ввода.
- [x] `paste` — вставка настоящим событием paste с clipboardData.
- [x] `type` c `delay` — посимвольный ввод: автодополнение и поиск с задержкой
      просыпаются только от реальных нажатий.

**Интерфейс.** Панель строилась под широкий десктопный сплит: кадр вписан по
ширине, прокрутка — только колесом.

- [x] Масштаб кадра (−/вписан/+) отдельно от размера окна Chromium.
- [x] Развернуть кадр на всю панель; Escape выходит.
- [x] Свайп пальцем прокручивает страницу.
- [x] Щипок двумя пальцами меняет масштаб кадра.
- [x] Клик после свайпа не проходит — иначе каждая прокрутка что-то нажимала.
- [x] Копирование адреса открытой страницы одной кнопкой.
- [x] Сочетания окружающего браузера: Alt+←/→, Ctrl/Cmd+R, Ctrl/Cmd+L, Escape.
- [x] Полоса выполнения вместо одного слова «Выполняется…».
- [x] Панель инструментов на узком экране прокручивается вбок, адрес закреплён сверху.
- [x] Стрелки и Backspace кнопками: экранная клавиатура телефона их не даёт.
