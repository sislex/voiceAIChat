# Playwright Reader: работа как у пользователя

Двадцать кругов улучшений с одной мерой: **модель в чате и в канбане должна
пользоваться браузером так же, как человек, а человек — работать с панелью и на
компьютере, и на телефоне.** Каждый круг — десять улучшений для модели и десять
для интерфейса, свой коммит, свой гейт.

Проверяется вживую на локальной сборке поверх прода: UI, playwright-reader,
web-reader, make и browser-runner идут из этого чекаута, а база, CLI и раны
остаются продовыми (`/private/tmp/voicechat-local-reader/launch.py`).

## Круг 1 — клавиатура, фокус и буфер обмена; кадр на любом экране

**Модель.** Умела кликать и печатать, но не умела дойти до элемента табом,
нажать сочетание и работать с выделением — то есть не умела ровно того, чем
человек пользуется постоянно.

- [x] `hotkey` — сочетание с удерживаемыми модификаторами (ctrl+a, meta+c, shift+Tab);
      модификаторы отпускаются даже при ошибке нажатия.
- [x] `press` c `repeat` — удержание клавиши (ArrowDown до нужной строки) одним вызовом.
- [x] `focus` — фокус на элемент без клика: клик по пункту меню и переход на него
      фокусом дают разные события, и ошибки доступности живут в этой разнице.
- [x] `focused` — что сейчас в фокусе: селектор, роль, значение, видимое кольцо
      фокуса, признак «внутри диалога» (ловушка фокуса в модальном окне).
- [x] `focus-order` — порядок обхода по Tab целиком, с положительным tabindex впереди.
- [x] `clear` — очистить поле, как Ctrl+A → Delete, с событиями input/change.
- [x] `select-text` — выделить текст элемента или страницы.
- [x] `copy` — прочитать выделение, включая выделение внутри поля ввода.
- [x] `paste` — вставка настоящим событием paste с clipboardData.
- [x] `type` c `delay` — посимвольный ввод: автодополнение и поиск с задержкой
      просыпаются только от реальных нажатий.

**Интерфейс.** Панель строилась под широкий десктопный сплит: кадр вписан по
ширине, прокрутка — только колесом.

- [x] Масштаб кадра (−/вписан/+) отдельно от размера окна Chromium.
- [x] Развернуть кадр на всю панель; Escape выходит.
- [x] Свайп пальцем прокручивает страницу.
- [x] Щипок двумя пальцами меняет масштаб кадра.
- [x] Клик после свайпа не проходит — иначе каждая прокрутка что-то нажимала.
- [x] Копирование адреса открытой страницы одной кнопкой.
- [x] Сочетания окружающего браузера: Alt+←/→, Ctrl/Cmd+R, Ctrl/Cmd+L, Escape.
- [x] Полоса выполнения вместо одного слова «Выполняется…».
- [x] Панель инструментов на узком экране прокручивается вбок, адрес закреплён сверху.
- [x] Стрелки и Backspace кнопками: экранная клавиатура телефона их не даёт.

## Круг 2 — формы целиком; телефонные жесты и форма глазами страницы

**Модель.** Заполняла форму полем за вызов и узнавала причину отказа только по
тому, что страница решила нарисовать.

- [x] `fill-form` — вся форма за один вызов, с отчётом по каждому полю;
      частично заполненная форма считается неуспехом.
- [x] `form-state` — поля, значения, обязательность и сообщение проверки;
      значение поля пароля не возвращается.
- [x] `validity` — что именно не даёт браузеру отправить форму и почему
      (`valueMissing`, `typeMismatch`, `rangeOverflow`…).
- [x] `submit` — отправка как по Enter: проверка браузера, затем обработчик.
- [x] `options` — варианты контрола: option у select, подсказки datalist,
      кнопки группы radio.
- [x] `drop-file` — файлы в зону перетаскивания: половина загрузчиков вообще не
      имеет `input[type=file]`, и туда `upload` не доходил.
- [x] `upload` нескольких файлов сразу, с общим бюджетом 8 МиБ.
- [x] `set` с несколькими значениями для `select multiple`.
- [x] Общий разбор base64 для загрузки и перетаскивания.
- [x] Ошибка поля не отменяет остальные поля формы.

**Интерфейс.**

- [x] Панель «Поля формы»: то же, что видит модель, — значения, обязательность и
      причина отказа проверки.
- [x] Долгое нажатие = правый клик (контекстное меню страницы с телефона).
- [x] Двойной тап = двойной клик; щелчки мыши так не склеиваются.
- [x] Масштаб кадра переживает переключение разговора и переоткрытие панели.
- [x] Очистка поля ввода кнопкой.
- [x] Размер окна Chromium подписан рядом с пресетами.
- [x] «Открыть у себя» — текущая страница в собственном браузере человека.
- [x] Список вкладок, когда их больше пяти.
- [x] Прокрутка отменяет начатое долгое нажатие.
- [x] Кадр не получает случайный клик после жеста.

## Круг 3 — дождаться и добраться до содержимого; поиск по странице

**Модель.** Имела плоское чтение и слепую прокрутку: на ленивой ленте она
останавливалась на первом экране, а причину «клик не сработал» узнать было нечем.

- [x] `wait` c `network: 'idle'` — сетевая тишина: данные догрузились, а не
      только разметка.
- [x] `wait` c `stable` — элемент перестал двигаться: анимация меню и модальных
      окон идёт после появления в DOM.
- [x] `scroll-until` — прокрутка ленты до цели, с паузой на подгрузку и честным
      ответом «дошли до конца, цель не появилась».
- [x] `count` — сколько элементов подходит (видимых и всего), без чтения текста.
- [x] `table` — строки записями под заголовками, с порциями и выбором колонок.
- [x] `list` — повторяющиеся блоки со своими кнопками: плоский текст терял,
      какая кнопка к какой карточке относится.
- [x] `metrics` — позиция прокрутки, высота страницы, сколько экранов ниже.
- [x] `measure` — геометрия элемента, перекрытие другим узлом и путь прокрутки
      до него: перекрытие липкой шапкой — обычная причина промаха клика.
- [x] `highlight` — рамка вокруг элемента прямо на странице.
- [x] Ответ `scroll-until` сообщает число прокруток и достигнут ли низ.

**Интерфейс.**

- [x] Поиск по странице внутри панели (Ctrl/Cmd+F): Ctrl+F браузера ищет по
      приложению, а не по странице в Chromium.
- [x] Счётчик совпадений «N из M».
- [x] Переход по совпадениям по кругу, Enter и Shift+Enter.
- [x] Совпадение показывается человеку: прокрутка к нему и рамка.
- [x] Кнопки «в начало» и «в конец» страницы.
- [x] «Ниже ещё N экранов» / «страница долистана».
- [x] Escape закрывает сначала поиск, потом разворот кадра.
- [x] Поиск доступен и кнопкой, не только сочетанием.
- [x] Метрики обновляются по действию, а не поллингом.
- [x] Панель поиска пригодна для телефона (высокие поля и кнопки).

## Круг 4 — среда, в которой сидит человек

**Модель.** Могла управлять страницей, но не условиями вокруг неё: тёмная тема
системы, уменьшенная анимация, высокий контраст, отсутствие сети и геопозиция
меняют поведение страницы, а воспроизвести их было нечем.

- [x] `emulate` c `colorScheme` — системная тёмная/светлая тема.
- [x] `emulate` c `reducedMotion` — уменьшенная анимация.
- [x] `emulate` c `forcedColors` — режим высокой контрастности.
- [x] `emulate` c `offline` — телефон без сети.
- [x] `emulate` c `geolocation` — координаты, вместе с выдачей разрешения.
- [x] `emulate` c `permissions` — разрешения сайта и их отзыв.
- [x] Эмуляция переживает переход и достаётся вкладке, открытой позже.
- [x] `cookies` — чтение, добавление и удаление по имени; длинное значение
      сокращается, потому что это доступ к аккаунту.
- [x] `media` — видео и аудио страницы: состояние, play/pause/mute/перемотка.
- [x] Отказ автовоспроизведения возвращается причиной, а не молчанием.

**Интерфейс.**

- [x] Панель «Среда» с переключателями темы, сети, анимации и контраста.
- [x] Подпись активной эмуляции в панели инструментов: на кадре она незаметна.
- [x] Сброс всей эмуляции одной кнопкой.
- [x] Cookies сессии видны человеку там же, где модели.
- [x] Позиция показывается, когда задана.
- [x] Переключатели работают парами (тема + контраст, сеть + перезагрузка).
- [x] Панель среды пригодна для телефона.
- [x] Состояние приходит от раннера, а не хранится в интерфейсе.
- [x] Cookies читаются по требованию, а не при каждом кадре.
- [x] Отказ команды показывается словами.

## Круг 5 — модель объясняет себя, человек видит её работу

**Модель.** Работала молча: человек смотрел на кадр и не понимал ни намерения,
ни порядка шагов — состояние страницы о них не говорит.

- [x] Лента сессии в раннере: обе стороны, в порядке событий, с итогом каждого
      действия (`SessionHistory`).
- [x] `history` — прочитать ленту, в том числе только свои или только чужие шаги.
- [x] `history` c `clear` — очистить ленту.
- [x] `note` — строка от модели в панель человека: чем она сейчас занята.
- [x] Заметка видна в ленте отдельно от действий.
- [x] Неудачная команда попадает в ленту с причиной: именно на ней видно, где
      модель застряла.
- [x] Чтение страницы в ленту не попадает — иначе это поток «прочитал, нашёл».
- [x] `expect` — несколько проверок одним вердиктом (текст, видимость, число,
      значение поля, адрес).
- [x] Несошедшаяся проверка показывает, что на странице вместо ожидаемого.
- [x] Упавшая проверка не отменяет остальные.

**Интерфейс.**

- [x] Панель «Что происходит» с лентой обеих сторон.
- [x] Фильтр: все / модель / я.
- [x] Заметки модели выделены в ленте.
- [x] Причина отказа рядом с записью.
- [x] Кнопка «показать элемент» у записи — подсветка на странице.
- [x] Время каждой записи.
- [x] Счётчик событий на кнопке.
- [x] Очистка ленты уходит командой, а не прячет её локально.
- [x] Свежие записи сверху.
- [x] Лента приезжает с метаданными кадра — без отдельного опроса.

## Круг 6 — данные страницы: хранилище, исходник, выгрузка

**Модель.** Видела страницу глазами, но не её данные: хранилище было доступно
только через `evaluate`, который политика проекта гейтит как опасный код.

- [x] `storage` — чтение localStorage и sessionStorage вместе с origin.
- [x] `storage` c `set` — запись значения.
- [x] `storage` c `remove` — удаление ключа.
- [x] `storage` c `clear` — очистка области.
- [x] Значения длиннее 500 символов обрезаются, но полный размер остаётся в `bytes`.
- [x] `storage` не считается выполнением произвольного кода и проходит там, где
      `evaluate` заблокирован политикой проекта.
- [x] `source` — исходная разметка порциями: атрибуты, скрытые поля, data-*.
- [x] `source` по селектору — разметка одного элемента.
- [x] `csv` — таблица целиком в CSV с экранированием кавычек и переводов строк.
- [x] `csv` порциями, как `table`.

**Интерфейс.**

- [x] «Хранилище сайта» в панели «Среда» — теми же данными, что видит модель.
- [x] Ключи показаны с областью, размером и значением.
- [x] Удаление ключа на месте, с перечитыванием.
- [x] Число ключей по областям и origin.
- [x] Признак «показана часть ключей».
- [x] Отказ показывается словами.
- [x] Чтение по требованию, а не на каждом кадре.
- [x] Та же панель, что cookies: человек смотрит их вместе.
- [x] Список пригоден для телефона.
- [x] Данные не кэшируются в интерфейсе между сессиями.

## Круг 7 — почему действие не сработало

**Модель.** Получала первую строку Playwright («Timeout 5000ms exceeded») и
повторяла тот же клик: у каждой беды свой следующий шаг, и именно его в
сообщении не было.

- [x] Разбор отказа на виды: не найден, неоднозначный, перекрыт, выключен,
      исчез, страница ушла, таймаут.
- [x] У каждого вида — причина словами человека.
- [x] У каждого вида — один конкретный следующий шаг, а не список возможностей.
- [x] Перекрытие отправляет в `measure`, который назовёт перекрывающий узел.
- [x] Исчезнувший элемент просит найти заново, а не повторить действие.
- [x] Таймаут отправляет ждать сетевую тишину.
- [x] Похожие элементы страницы прикладываются к отказу: «нет элемента» — это
      половина ответа, человек в этот момент видит кнопку с другой подписью.
- [x] Кандидаты ищутся и по совпадению начала подписи («Сохранить» ↔ «Сохранить как»).
- [x] Недоступная страница не мешает вернуть причину.
- [x] Незнакомая ошибка отдаётся как есть, без выдуманного совета.

**Интерфейс.**

- [x] Панель показывает причину вместо строки Playwright.
- [x] Совет — следующим шагом рядом с ошибкой.
- [x] Похожие элементы кнопками: нажатие ищет их на странице.
- [x] Отмечено, что кандидат выключен или скрыт.
- [x] Отказ селекторного действия больше не молчит (раньше значение `ok: false`
      не показывалось вовсе).
- [x] Причина сбрасывается при следующей команде.
- [x] «Повторить» осталось для команд, которые того стоят.
- [x] Причина и совет читаются на телефоне.
- [x] Отказ не ломает ленту событий.
- [x] Разбор общий для человека и модели — одна формулировка.

## Круг 8 — сценарий как результат работы модели

**Модель.** Проходила путь ровно как человек, но на выходе оставался только
текст хода: воспроизводимого сценария из него никто не восстановит, а в задаче
канбана нужен именно он.

- [x] `record start/stop/status` — запись сценария из собственных действий.
- [x] Шаги пишутся в формате сценариев проекта (`AutomatedQaScenario`).
- [x] Читающие действия (`read`, `find`, `screenshot`, `metrics`…) в запись не идут.
- [x] Стартовый адрес берётся из первого `open`.
- [x] `record-check` — проверка прикрепляется к последнему шагу («нажал — увидел»
      это одно событие).
- [x] Проверка отсутствия текста — отдельным полем шага.
- [x] Длинная запись обрезается и честно считает пропущенное.
- [x] Запись живёт в MCP-слое, где известно исходное действие модели: до раннера
      доезжает команда Chromium, из которой селекторный шаг не собрать.
- [x] `replay` — прогон записанного или переданного сценария по шагам.
- [x] Прогон останавливается на первом упавшем шаге и называет причину.

**Интерфейс.**

- [x] Шаг двигается вверх и вниз: записанный проход почти никогда не идеален.
- [x] Шаг выключается, оставаясь в записи, — заготовка, а не мусор.
- [x] Выключенный шаг приглушён и зачёркнут.
- [x] Выключенный первый переход не задаёт стартовый адрес.
- [x] Сценарий вставляется из JSON: перенос между разговорами и стендами.
- [x] Ошибка разбора JSON объясняется словами.
- [x] Правка шага сбрасывает отметки прошлого прогона.
- [x] Кнопки правки не мешают прежним (прогон до шага, удаление).
- [x] Копирование сценария осталось на месте.
- [x] Предупреждения о ненадёжных и сломанных шагах продолжают работать.

## Круг 9 — настоящий мобильный веб, а не узкое окно

**Модель и панель.** «Телефон» означал только ширину: страница верстается как
мобильная, но `maxTouchPoints` равен нулю, `pointer: coarse` не срабатывает, а
`devicePixelRatio` остаётся единицей — ровно на этом ломаются карусели, меню «по
наведению» и всё, что отличает палец от мыши.

- [x] `device` — устройство целиком: размер, плотность пикселей, тач,
      ориентация, user agent.
- [x] Пресеты phone, phone-android, tablet, desktop.
- [x] Ландшафт меняет стороны и угол экрана.
- [x] `desktop` снимает эмуляцию тача.
- [x] Неизвестный пресет называет доступные, а не берёт десктоп молча.
- [x] Свои размеры перекрывают пресет.
- [x] `touch` — жест пальцем: tap, swipe, long-press.
- [x] Свайп идёт шагами: мгновенный перенос пальца страница не засчитывает.
- [x] Долгое нажатие действительно держит палец.
- [x] Невидимый элемент — отказ, а не касание в углу экрана.

**Интерфейс.**

- [x] Пресеты панели включают устройство целиком.
- [x] Кнопка поворота для мобильных пресетов.
- [x] Подпись «тач» и плотности пикселей рядом с размером.
- [x] Старый раннер без `device` оставляет прежний ресайз — человек всё равно
      видит мобильную вёрстку.
- [x] Размер сессии обновляется вместе с устройством: снимки и координаты
      считаются по нему.
- [x] Поворот не сбрасывает выбранный пресет.
- [x] Кнопка поворота не показывается для десктопа.
- [x] Состояние устройства приходит от раннера.
- [x] Пресеты остались на прежнем месте панели.
