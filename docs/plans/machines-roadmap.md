## Процедура проверки на стенде

```bash
S=<scratchpad>; bash $S/restart-stand.sh                       # сервер :8799, данные в $S/make-data
# машина «stand-mac» уже зарегистрирована для bob (token в $S/agent.json); агент с подменённым HOME:
cd apps/agent && HOME=$S/fakehome VC_AGENT_SERVER=ws://127.0.0.1:8799/agent VC_AGENT_TOKEN=<token> npx tsx src/index.ts
```
Хранилище по умолчанию появляется в `$S/fakehome/ChatAI`. Проверки API — curl с Bearer-токеном bob (`POST /api/session/login`), UI — вкладка Chrome на `http://127.0.0.1:8799`. Осторожно: `pkill -f "tsx src/index.ts"` убивает и агент, и сервер.
