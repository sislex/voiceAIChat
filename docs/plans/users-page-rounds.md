# Страница «Пользователи» и «Мой аккаунт» — круги улучшений

Живая реализация: `packages/admin-app/src/users/*` (страница), `packages/profile-app`
(карточка человека, общая с `#/account`), `packages/ui-kit` (примитивы),
`apps/server/src/routes/{admin,rest}.ts` (данные). Макет — Make-публикация
`/p/cae6955712984a7dbde8ff4ef639f3b3/`.

Правило кругов: круг засчитывается только после зелёного `npm run gate` **по коду
возврата** и проверки глазами в браузере. Данные не выдумываем: нет источника —
честное пустое состояние либо доработка сервера.

## Круг 1 — страница есть, но она ещё дороже и грубее, чем должна быть

После первой сборки остались измеримые долги: список грузится целиком без предела,
поиск фильтрует на каждый символ, журнал тянется в двести событий ради пяти строк
обзора, а данные вкладки перезапрашиваются при каждом возврате на неё. Плюс мелочи
интерфейса, которые видно глазами, но не видно тестам.

| № | Пункт | Статус |
