# Логин и регистрация — roadmap

Статусы: ✅ сделано · ⏸ ждёт внешнего ресурса (SMTP, OAuth-клиенты) · ✗ пропущено (причина в строке).
Выполняется сразу после `make-roadmap-4.md`, по тем же правилам (гейт, стенд :8799, KB + коммит, релиз каждые 5 пунктов).
Текущее состояние: пароли — scrypt с солью (`users/passwords.ts`), вход по имени+паролю, пользователей создаёт админ, саморегистрации нет, токен сессии в localStorage.

## Безопасность входа
| № | Пункт | Статус |
|---|---|---|
| 1 | Rate-limit `POST /api/session/login`: 10 попыток / 10 мин по IP и по имени, 429 + Retry-After | ✅ `SlidingWindowLimiter` ×2 в `users/auth.ts` (по IP и по имени, скользящее окно), 429 + `Retry-After` + `retryAfterSec` в теле |
| 2 | Политика пароля: запрет пустого, минимум 10 символов; проверка по утечкам (HIBP k-anonymity) — опционально | |
| 3 | Блокировка аккаунта после N неудач (счётчик в БД), уведомление админу | |
| 4 | Сессии с TTL и отзывом: таблица сессий (устройство, IP, last seen), «выйти везде», список в админке | |
| 5 | Токен в HttpOnly-cookie + CSRF-токен для мутаций вместо localStorage | |
| 6 | 2FA (TOTP) для admin; passkeys/WebAuthn как следующий шаг | |
| 7 | Журнал безопасности: вход/выход/смена пароля/неудачи с IP и UA, страница в админке | |
