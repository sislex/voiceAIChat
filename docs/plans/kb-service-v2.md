# kb-service-v2 — базы знаний Kanban и Core UI, подключение модулей и сокращение тем ядра

Ран `kb-service-v2`. Ветка задач — `dev`. Продолжение `kb-service-v1`.

Сейчас: базы знаний есть у Make, агента, Playwright Reader и Web Reader (8–10 тем), у Kanban и Core UI —
заготовки; ядро по правилу «сначала копия у владельца» держит все 22 темы, включая `projects.md`
(Kanban, 2428 строк) и `ui.md` (Core UI, 5048 строк). На проде подключены только модули проектов
(`make`, `voiceaichat` — дубль `core`): модули регистрирует Kanban по `gitUrl` проекта, а у агента и
читалок проектов нет.

Исходные темы ядра скопированы интегратором в `docs/kb/import/` Kanban (`core-projects.md`) и Core UI
(`core-ui.md`, `core-operations-app.md`, `core-admin-app.md`, `core-conversation-groups.md`) вместе с
`vendor/sislexa-kb-tools-0.1.0.tgz` (тот же архив, что в Make).
