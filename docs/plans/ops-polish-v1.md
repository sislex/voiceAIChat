# ops-polish-v1 — хвосты после kanban-speed-v1

Ран `ops-polish-v1`. Ветка задач — `dev`. Задачи выполняют воркеры MacBook (M2); M1 выключен.

## Что случилось

1. **Воркеры Delivery Control клонируют с GitHub, когда замок зеркала занят.** `src/worker/warm-workspace.ts:223-243`
   (`checkoutWithMirror`): замок — `mkdir(<mirror>.lock)` без PID, возраста и ожидания; при `EEXIST` (:228) сразу
   `git clone` с GitHub и результат `busy`. На медленном канале Mac (≈1 МБ/с до GitHub) такой клон Core идёт 10–20 минут
   (B02/B03 kanban-speed-v1 висели на нём). Брошенный замок упавшего держателя не снимается никогда — тогда каждый клон
   идёт мимо зеркала.
2. **Превью стенда молча пустое при входе через `http://<host>:8787`.** Стенд и Storybook отдаются по
   `https://<host>:8790-8794` с самоподписанным сертификатом; пока пользователь не принял сертификат на
   `https://<host>`, iframe (`MakePreviewHost.tsx:394-400`, без onError и таймаута) пустой, подсказки нет.
3. **Флаки `scripts/affected-check.test.mjs` под нагрузкой** (load average до 49 на 8 ядрах): сравнение
   `parallelMs < sequentialMs` (:212), heartbeat с интервалом 10 мс внутри `delay(15)` (:169-190), опросы 500×20 мс
   после `spawnSync` (:420, :701) и `spawnSync` с `timeout: 10000` (:693).
4. **Флаки e2e Playwright Reader «экспорт Blob из настоящего iframe Make»** (`system-tests/playwrightReader.e2e.test.ts`
   в `sislex/playwrightreader`): два `expect.poll` с умолчанием 10 с (кадр Make в `frames`, загрузка `completed`) вместо
   `SYSTEM_HOST_TIMEOUT`; тест зависит от состояния предыдущих (сброшенные cookie, оставшийся диалог beforeunload).
5. **`readinessProbe.test.ts` Kanban падает, когда порт 23000 занят** (шлюз стенда): тест «uses real loopback binds to
   skip an occupied port» (:78-83) делает настоящий `bind(('127.0.0.1',23000))`.
