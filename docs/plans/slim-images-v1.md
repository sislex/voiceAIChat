# slim-images-v1 — тонкие образы фронтендов и API приложений

Ран `slim-images-v1`. Ветка задач — `dev`. Решение владельца (2026-10-06) после разбора диска прода.

Образы, которые только раздают статику, весят около гигабайта (`webreader-frontend` 1,3 ГБ,
`playwrightreader-frontend` 1,17 ГБ, `make-frontend` 917 МБ), хотя собранные файлы — 5–60 МБ: стадия
`frontend` копирует весь `/app` (исходники и все node_modules) и запускает сервер статики через `tsx`.
API-образы тоже несут dev-зависимости. Цель — меньше места на проде и на машинах стендов и быстрее
скачивание образов при деплое.
