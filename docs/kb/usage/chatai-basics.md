# Как пользоваться ChatAI

Статья раздела «Использование»: он общий для всех пользователей и отвечает на вопрос
«как работать с приложением», а не «как оно устроено внутри».

## Разговор

Чат создаётся кнопкой «Новый» в боковой панели. Писать можно текстом или голосом:
кнопка микрофона включает распознавание, распознанный текст попадает в поле ввода, а
ответ модели при включённой озвучке читается вслух. Ход модели живёт на сервере — если
вкладка закрылась или связь оборвалась, ответ всё равно сохранится в истории.

## Проекты и задачи

Проект связывает чаты, канбан-доску, машины и знания по разработке. Чат можно привязать
к проекту — тогда модель получает контекст проекта и его раздел базы знаний. Участники
проекта добавляются владельцем; всё, что принадлежит проекту, видно только участникам.

## Машины

Машина — компьютер с установленным агентом, на котором модель выполняет команды.
Машина привязывается к проекту вместе с рабочей папкой; без неё модель работает без
доступа к репозиторию.

## База знаний

Три раздела: «Использование» (эта статья), «Настройки пользователя» — ваши личные
записи о предпочтениях, и «Разработка проекта» — знания о коде выбранного проекта.
Кнопка «Исследовать проект» просит модель просканировать репозиторий на машине проекта
и обновить его статьи по коду. Во время ответа модель может вызвать инструмент базы
знаний `mcp__kb__runtime_context`: он показывает только контекст текущего чата,
его привязанный проект и эффективную пару LLM, без секретов и чужих настроек. Для
проверки настроек владельца того же чата есть `mcp__kb__user_settings`; в нём
доступны выбор LLM, режим прав, режим БЗ и машина по умолчанию.

Полный справочник личных настроек, расхода, машин и проектов — [«Информация о пользователе»](user-account.md). Там же перечислены инструменты, которые модель может вызвать сама, и безопасные границы доступа.
