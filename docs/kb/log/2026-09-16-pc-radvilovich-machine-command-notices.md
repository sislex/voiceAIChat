# machine-command-notices

## Что сделано

- Актуализированы знания о публикации и пользовательской политике уведомлений завершившихся команд машин.

## Что выяснили (факты, которых не было в KB)

- `machine.command` публикует модуль машин через пользовательский frame hub; UI всегда пишет событие в историю, а тост и системное уведомление фильтрует серверными настройками.
- Длительность сервер принимает в диапазоне 0–120 секунд; UI предлагает 0, 4, 8, 15 и 30 секунд, а режим `off` блокирует зависимые контролы без сброса.
