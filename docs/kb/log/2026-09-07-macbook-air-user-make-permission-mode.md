# make-permission-mode

## Что сделано

Актуализирована тема LLM после исправления сброса режимов Make: зафиксированы правила вычисления принудительного плана в UI и передачи режима сервером.

## Что выяснили (факты, которых не было в KB)

Make-разговор не понижается до plan из-за отсутствующей машины. Сервер сохраняет выбранный режим для Claude и Codex, а read-only определяется итоговым режимом хода через параметр `ro=1` Make MCP. Встроенные инструменты при этом всегда запрещены.
