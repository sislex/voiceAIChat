# release-version-footer

## Что сделано

- Актуализирована схема передачи версии фактически развёрнутого приложения до футера web-интерфейса.

## Что выяснили (факты, которых не было в KB)

- Защищённая публикация передаёт каноническую версию через `VC_RELEASE_VERSION`; для обычного deploy fallback — строгий тег `vX.Y.Z` текущего `HEAD`.
- При отсутствии обоих источников backend возвращает `version: null`, а UI не рендерит версию вместо показа технического номера.
- Версия приложения приходит во frontend во время выполнения через `app:ping` и не совпадает с `AGENT_VERSION` компаньон-агента.
