# image-studio-order-select

## Что сделано

Итерация 59 студии картинок (14 пунктов): порядок сетки выбирается селектом из
восьми вариантов (было — кнопка-цикл), разворот вынесен в кнопку `↓`/`↑`,
список порядков экспортируется как `IMAGE_STUDIO_ORDERS`; блок запретов «без
чего» свёрнут в кнопку «Без…» со счётчиком и памятью состояния. Четырнадцать
тестов переписаны, добавлены два новых.

## Что выяснили (факты, которых не было в KB)

- **Кнопка-цикл порядка врала.** Подпись собиралась цепочкой тернарников без
  ветки для `tint`, поэтому «По цвету» показывалось как «Сначала готовые».
  Такие цепочки «значение → подпись» надо держать таблицей: тогда новый вариант
  без подписи не компилируется.
- Разворот порядка жил на Shift+клике — с клавиатуры он недостижим, и ни один
  тултип об этом не говорил (кроме самого тултипа кнопки).
- Механическая замена «клик по кнопке порядка» на «выбор в селекте» оставляет
  в тестах цепочки промежуточных переключений (`name` → `size` → `pixels` →
  `stars`), которые больше ничего не проверяют: их надо схлопывать до одного
  выбора нужного значения.

- Следующие кандидаты: строка «Поделиться» (публикация галереи) и мультирежим
