# kanban-board-scroll

## Что сделано

- Актуализировано описание прокрутки канбан-доски после перехода на общую поверхность колонок.

## Что выяснили (факты, которых не было в KB)

- `.jboard` прокручивает всю доску по обеим осям; `.jcol-body` растёт по карточкам без собственного вертикального скролла.
- Pointer-DnD карточек автопрокручивает `.jboard` по горизонтали и вертикали, а фильтры остаются вне этой поверхности.
