# task-card-design-round1

Карточка открытой задачи приведена к макету
`http://89.125.68.35:8787/p/8d2a107ea0e9445fb80524c3bcae7b49/index.html`
(публикация Make, в репозитории её нет — скачивалась курлом).

## Что сделано

- **Язык панелей рана в ui-kit**: `StatusPill`, `PanelHeading`, `MetricGrid`,
  `StepList`, `ProgressTrack`/`ProgressRing`, `FeedItem`/`FeedLog`, `SubTabs`,
  `LiveIndicator` — с DOM-тестами рядом и общей сторис `UI/Run panels`.
  Классы `.vc-feed-*` переехали из `app.css` в `packages/ui-kit/src/styles.css`.
- **Шапка карточки**: надстрочная строка «ключ · точка состояния · этап» и
  крупное название под ней; действия задачи ушли в `⋯`-меню на любой ширине.
- **Полоса вкладок**: счётчик вынесен из скобок подписи в пилюлю `.task-tab-count`.
- **Колонка свойств** вынесена из панели «Общего» в соседа `.jmodal-panels` —
  видна на любой вкладке; строка свойства стала сеткой «подпись | значение»,
  добавлена строка «Проект».
- **Вкладка «Общее»**: секции `.task-section` с текстовым «Редактировать»,
  прогресс подзадач, создание подзадачи (`onCreateSubtask`), секция «Активность».
- Панели вкладок получили `PanelHeading`; подготовка — ещё `MetricGrid` вместо
  пяти лозенг подряд.

## Что выяснили (факты, которых не было в KB)

- `CiRunSummary` **не несёт временных меток** (`createdAt`/`updatedAt` в нём нет) —
  поэтому активный ран в компактной ленте «Активность» показывается без времени,
  а датированные события берутся из полей `Task`.
- У задачи нет комментариев: ни таблицы, ни поля в `Task`
  (`task_comments`/`checklist`/`attachments` в схеме отсутствуют). Композер
  комментария из макета не реализуем без схемы БД + REST + WS — вместо него
  «Активность» собрана из уже загруженных полей и ведёт в связанный чат.
- Потомки бывают только у эпика (стори) и стори (задача) — «Добавить подзадачу»
  у обычной задачи не показывается.
- `.storybook/main.ts` **не** включает `packages/ui-kit/**` в globs сториз:
  витрина примитива обязана лежать в `packages/ui/src/components/ui/`.
- Сторож `taskCardStyles.test.ts` читал только `app.css` — после переезда классов
  в ui-kit он читает оба файла.

## Открытые вопросы / что осталось

- Живая проверка в приложении не делалась: dev-сервер не поднят, а вход требует
  пароля пользователя. Проверено витриной (Chrome MCP, светлая и тёмная тема,
  1440 и 390px), `npm run gate` и бюджетом чанков.
- Настоящие комментарии к задаче — отдельная задача (схема БД + REST + WS).
- Панели QA/Merge переведены на общий язык только по шапкам; их внутренности
  (`qa-score`, `test-grid`, `gate-list`, `merge-card`) — следующий круг.
