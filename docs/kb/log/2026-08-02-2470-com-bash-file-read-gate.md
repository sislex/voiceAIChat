# bash-file-read-gate

## Что сделано

- Гейт чтения файлов в MCP-инструменте `bash` (`apps/server/src/mcp/bashFileRead.ts`):
  команда, у которой нет смысла кроме чтения файла внутри `cwd`, отклоняется до
  `exec` и возвращает готовый вызов `read` с окном строк. Разбор — свой
  токенизатор с кавычками: пайплайн, фоновый `&`, редирект, подстановка, glob и
  тильда снимают вопрос сразу; цепочки `cd`/`echo` + чтения разбираются целиком.
- Отдельный вид `denied` в `ci_run_tool_calls` и в отчёте задачи («· отказов N»).
  Отказ узнаётся по тексту результата (`isCiToolDenial`), в «всего вызовов» не
  входит, ход из одних отказов счётчик всё равно пишет.
- Промпты обоих движков и описание инструмента предупреждают о гейте заранее.
- `scripts/ci-usage-report.mjs` печатает отказы (и восстанавливает их из ленты
  для ранов до метрики).

## Что выяснили (факты, которых не было в KB)

- В ленте ранов подавляющее большинство чтений записано как
  `cd <абсолютный путь рабочей копии> && sed -n 'A,Bp' <файл>` — гейт, который
  смотрит только на одиночную команду, не закрыл бы почти ничего. Поэтому `cd` и
  `echo` считаются нейтральными сегментами, а база путей после `cd` учитывается
  при построении подсказки.
- Точный текст отказа claude в headless: «Claude requested permissions to write
  to /tmp/chatMode.test.ts, but you haven't granted it yet.» — по нему и считаем
  отказы CLI (проверено на ране `dfcd9e0e` в прод-БД).
- Читать файл командой приходится там, куда `read` не дотянется: `/tmp/*.log`,
  `node_modules`, содержимое CLI-пакетов. Такие команды гейт обязан пропускать —
  иначе он ломает работу, а не экономит контекст.
- `apps/server/src/db/schema.ts` — один шаблонный литерал, поэтому обратная кавычка
  в SQL-комментарии закрывает строку и роняет разбор всего файла (правка `06abc2a`
  снимала именно это: комментарий про новый вид `denied` был написан с бэктиками).
  Занесено в `data-auth.md`.

## Открытые вопросы / что осталось

- Проверить долю чтений на контрольном ране: цель — не больше 5 чтений через
  `bash` при доле `read` ≥ 90%.
- Правки heredoc'ом гейт не трогает (их и осталась одна) — если вернутся,
  запрет строится по тому же принципу.
