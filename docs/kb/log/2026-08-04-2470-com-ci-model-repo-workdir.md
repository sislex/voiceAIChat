# ci-model-repo-workdir

## Что сделано

- Remote-MCP работы модели, fix-loop и KB-update переведены с родительского workspace на корень клонированного репозитория.
- Связанный чат задачи получает машину и точный путь клона при старте рана.
- Перед моделью добавлена проверка `git rev-parse` в ожидаемом корне; ошибка останавливает ран и откатывает карточку.

## Что выяснили (факты, которых не было в KB)

- Боевые команды ChatAI запускаются из `{repos_root}/{project}/{task_number}` и сами делают `cd $SLUG`, поэтому путь команд и путь MCP модели различаются.
- Успешное завершение CLI само по себе не доказывает наличие checkout: без проверки пустой ход мог пройти до merge и ложного success.
