# Резюме CI-рана в связанном чате + имя чата задачи

## Что сделано

- Шаг «Резюме модели» дополнительно уходит отдельным AI-сообщением в связанный чат
  задачи: `postSummaryToChat` в `CiRunManagerDeps` (проводка — `server.ts`), шапка
  `Резюме по задаче <PRJ-N> · <заголовок>`, метка `TurnMeta.ciRunSummary = { runId }`.
- Новое WS-сообщение `chat.message` (`{ conversationId, message }`): открытый чат
  дописывает резюме сразу. Мост — `window.ci.onChatMessage`, стор — `applyChatMessage`
  (через `appendPersisted`, дубли по `id` отбрасываются).
- Имя нового связанного чата — «Задача &lt;заголовок&gt;». Одноразовая миграция
  переименовывает старые чаты задач, у которых имя всё ещё равно заголовку карточки.
- Тесты: `ci/runManager.test.ts` (сообщение с меткой, кадр `chat.message` по WS,
  резюме при упавшем слоте «после»), `db/database.projects.test.ts` (имя по умолчанию
  + миграция, включая «второй старт не наращивает префикс»), `shared/protocol.test.ts`,
  `ui/store/voiceStore.projects.test.ts` (`applyChatMessage`).

## Что выяснили (факты, которых не было в KB)

- Сообщения, которые сервер дописывает в чат сам (вопросы CI-рана), до этой правки
  никак не доезжали до открытого чата — не было WS-канала для «просто сообщения»,
  только события хода (`claude.*`). Теперь такой канал есть (`chat.message`), и вопросы
  тоже можно на него перевести.
- Резюме считается уже после слота «после», поэтому падение финальных команд не
  лишает задачу резюме — ран `failed`, а сообщение в чате есть.
- Полный `npm run -w @voicechat/server test` в этой копии подвисает на параллельном
  прогоне; проверяли пофайлово (`npx vitest run <файлы>` из корня) — зелено.

- docs/kb/projects.md — имя связанного чата и миграция старых имён.
- docs/kb/protocol.md — WS `chat.message` и мост `onChatMessage`.

## Открытые вопросы / что осталось

- Вопросы модели в чате (`postToChat`) живой доставки по-прежнему не имеют — их
  можно перевести на тот же `chat.message` отдельной правкой.
- UI не показывает у резюме отдельной плашки/ссылки на ленту рана: метка
  `ciRunSummary` есть, рендер — обычное AI-сообщение.
