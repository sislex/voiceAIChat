# image-studio-improvements-54

## Что сделано

- Итерация 54 (последняя в серии; пользователь остановил цикл): модуль
  `lib/imageIntake.ts` (безопасное имя загрузки, порог уменьшения, шаблоны
  промптов с переменными, средний цвет/оттенок/расстояние, диапазон
  выделения), шаблоны промптов с подстановкой, «Похожие по цвету» и порядок
  «По цвету», лупа с координатами и цветом под курсором, клавиша `i`,
  `Shift+стрелки`, кнопка «Показ», пакетное «По промпту», настраиваемый
  размер страницы, память свёрнутой панели рисования, строка состояния в
  футере, поиск по истории промптов, «Сбросить фильтры» сбрасывает и порядок
  с группами, битые файлы отмечаются после проверки, предупреждения о
  большом файле и предложение уменьшить огромную картинку.

## Что выяснили (факты, которых не было в KB)

- `copyName` всегда дописывает «-копия» — он про дубликаты. Там, где нужно
  «взять имя как есть и отойти только при совпадении», нужна своя проверка
  `taken.has(wanted)`.
- `nameFromPrompt` берёт только первые три слова промпта (правило имени:
  коротко) — тесты и ожидания надо строить по этому, а не по всему тексту.
- Хоткей в **подписи** кнопки ломает тесты и имя для читалки: клавишу пишем
  в `title`, подпись оставляем прежней.
- Средние цвета файлов нельзя считать все сразу: партии по четыре через
  `mapWithLimit` — сотня параллельных `createImageBitmap` подвешивает вкладку.
