# web-reader-diagnostics

## Что сделано

- Дополнены темы UI и клиент-серверного протокола по реализованной самодиагностике Web Reader.

## Что выяснили (факты, которых не было в KB)

- Диагностика запускается кнопкой или одной из двух точных команд, заранее публикует перечень проверок и сохраняет пошаговый результат без хода LLM.
- Сценарий использует внутреннюю same-origin страницу, привязку conversation/request/registration и исключает диагностические действия из recorder.
