# cold-start-history-boundaries

## Что сделано

- `historyText` принимает сообщение хода и обрезает историю на нём: вопрос, поставленный в очередь за идущим ходом, больше не попадает в запрос этого хода.
- Остановленный пользователем ответ остаётся в запросе следующего хода пометкой «остановлен» (пустой — отдельной пометкой, частичный — текстом с пометкой).

## Что выяснили (факты, которых не было в KB)

- Прод 0.1.571, Chat: два вопроса подряд («три предложения про лес», затем «одним словом: очередь») — оба ответа «Очередь»: первый ход получил в истории и второй вопрос. Проявляется во всех ходах без сессии движка (Chat, Required, приложения через API моделей).
- Стенд через транзит: после «Стоп» на ходе с командой `sleep 40` следующий вопрос заново выполнил остановленную команду (44 с) — пустой остановленный ответ в историю не попадал, и запрос выглядел неотвеченным.

## Открытые вопросы / что осталось

- Инспектор контекста (`routes/rest.ts`) строит оценку истории своим списком сообщений и пометок остановки не учитывает — расхождение в несколько десятков символов.
