# qa-panels-teardown

## Что сделано

- Уточнён lifecycle браузерного набора QA-панелей: асинхронные операции teardown ожидаются полностью, а их ошибки сохраняют ненулевой результат гейта.
- Зафиксирована неизменность read-only API просмотра временных ресурсов без передачи пути на удаление.

## Что выяснили (факты, которых не было в KB)

- Закрытие Playwright и остановка группы Storybook выполняются независимо через settled-ожидание; ошибка одной операции не прерывает вторую.
- Одиночная ошибка cleanup пробрасывается без обёртки, несколько ошибок объединяются в `AggregateError`.
