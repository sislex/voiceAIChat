# Info-подсказка шагов CI-рана

## Что сделано

- Рядом со счётчиком прогресса RunFeed добавлена доступная Info-кнопка.
- Popover показывает фактические шаги рана, состояния и активный шаг.
- Добавлены сценарии мыши, клавиатуры, touch и длинного pipeline.

## Что выяснили (факты, которых не было в KB)

- Прогресс слотов соответствует корневым шагам; вложенные model_command в него не входят.
- Фактический порядок UI получает из CiRunDetail.steps по position.
