# image-studio-improvements-1

## Что сделано

- Итерация 1 улучшений студии картинок (10 шт.): Cmd/Ctrl+Enter, автофокус
  промпта, фокус поля переименования, секундомер генерации, баннер ошибки в
  панели, лайтбокс (ToolFrame), drag&drop + мультизагрузка, копирование в буфер,

## Что выяснили (факты, которых не было в KB)

- autoFocus у появляющегося инпута в React с порталами срабатывает ненадёжно —
  фокус ставим эффектом по появлению состояния (видели живьём: поле открылось,
  ввод ушёл в страницу).
- В jsdom у File нет arrayBuffer — в dom-тесте загрузки его доопределяют на
  объекте файла.
