# popup-file-terminal-context

## Что сделано

- Добавлен единый `PopupFrame` и на него переведены все dialog-popup UI.
- Из картинки можно открыть проводник на её машине; проводник открывает родителя и выделяет файл.
- Сайдбар открывает проводник/терминал на машине активного разговора.
- Проводник открывает PTY в текущей папке; `cwd` проходит через весь протокол до агента. Это работает и для отдельного popup, и для встроенного блока проводника в сообщении.

## Что выяснили (факты, которых не было в KB)

- Контекст машинной утилиты должен хранить одновременно `agentId` и `path`; иначе переходы между картинкой, проводником и терминалом теряют машину или каталог.
- Поддержка начального cwd требует агента 0.9.0.
