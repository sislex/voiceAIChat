# Синхронизация студии картинок с main

## Что сделано

- После fetch подтверждено: рабочий HEAD и `origin/main` совпадают (`c8fcb5e8`), fast-forward с `eb4e281f` уже присутствует в reflog.
- Сохранены локальные изменения студии и обновления main по моделям/прайсам. В начальном дереве отсутствовали ранее добавленные Docker-стадия студии, зависимость ядра, регистрация внутреннего API и запись в графе гейта; эти подключения восстановлены, lockfile перегенерирован.
- Восстановлены записи KB о границах Make и студии; изменения main в статье shared сохранены.
- Итоговый `npm run gate:fast` прошёл с кодом 0: общий typecheck и полный набор тестов (7506 успешных Vitest-тестов). Сборка web и проверка diff также прошли.
- Адресная проверка адаптеров студии и серверного smoke-теста: 40 тестов прошли. Конфигурация Compose валидна.

## Что выяснили (факты, которых не было в KB)

- Совпадение HEAD с origin/main и отсутствие текстовых конфликтов не гарантируют целостность незакоммиченного выделения пакета: нужно сверять манифесты, граф гейта, Docker target и регистрацию RPC вместе с сохранённым кодом.

## Куда занесено

- `docs/kb/server-internals.md`, `docs/kb/shared.md`.

## Открытые вопросы / что осталось

- Изменения студии остаются локальными; commit, push и production deploy в этом шаге не выполнялись.
