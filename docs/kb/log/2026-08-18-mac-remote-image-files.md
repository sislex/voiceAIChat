# remote-image-files

## Что сделано

- Сверено с `main` и рабочим кодом поведение передачи вложений чата в `remote:image`.
- Дополнена файловая тема о машинах ссылками на источники реализации.

## Что выяснили (факты, которых не было в KB)

- Вложения регистрируются в `RemoteFileBroker` по токену только на время хода.
- `remote:image` разрешает путь как вложение → cwd → папка проекта → абсолютный путь, определяет JPEG/PNG/GIF/WebP по сигнатуре и возвращает MCP `ImageContent` без base64 в тексте.
- Отсутствующий файл и найденный неподдерживаемый формат различаются; сгенерированный результат переносится в `.generated_images` исходной машины.
