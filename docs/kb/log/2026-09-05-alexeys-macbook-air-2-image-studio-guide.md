# image-studio-guide

## Что сделано

Экран «Что умеет студия картинок» — тринадцать разделов с оглавлением и
двенадцатью снимками экрана, кнопка `ⓘ` в тулбаре галереи. Снимки сняты с
живого стенда и лежат в `packages/ui/src/assets/imageStudio/`. Плюс dom-тест
(все разделы отрисованы, у снимков есть подписи) и сториз.

## Что выяснили (факты, которых не было в KB)

- **В UI-пакете до этого не было ни одной растровой картинки** — интерфейс
  обходился CSS и эмодзи. Импорт `.jpg` работает без дополнительной настройки:
  типы даёт `vite/client`, путь превращается в URL сборкой Vite, поэтому один
  и тот же код годится и для web, и для Electron.
- Снимки для документации удобно снимать действием `computer.zoom` с `region`
  и `save_to_disk`: получается прицельный кадр без ручной обрезки. Обычный
  `screenshot` даёт всю вкладку и мелкие детали.
- **`document.documentElement.style.zoom` ломает позиционирование `fixed`**:
  шапка лайтбокса уезжала за верх экрана (`top: -60`). Для полноэкранных окон
  зум надо возвращать к 1, крупный кадр брать регионом.
- Скриншоты ужимаются `sips -Z 1200 -s formatOptions 72`: двенадцать кадров
  укладываются в 650 КБ, и это единственный вес, который добавился в бандл —
  в разметке у снимков `loading="lazy"`.
