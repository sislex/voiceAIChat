# Замер отдельных гейтов Web Reader и его UI

## Что сделано

- На чистом SHA `17dd72ff`, совпадающем с `origin/main`, последовательно запущены
  `npm run gate:app -- web-reader` и `npm run gate:app -- web-reader-ui` через
  `scripts/long-run.mjs` и `/usr/bin/time -p`. Исходники не менялись.
- Среда: macOS arm64, Apple M2 (8 CPU), 24 ГБ RAM, Node 22.19.0; зависимости уже
  установлены. Успешные запуски выполнены вне песочницы с разрешением пользователя.

## Что выяснили (факты, которых не было в KB)

- Web Reader: код 0, 112,86 с wall time. API — 410 тестов / 4,48 с;
  рекордер — 85 / 1,74 с; мосты ядра — 28 / 3,00 с; E2E — 209 / 67,38 с.
- Web Reader UI: код 0, 22,54 с wall time. Панель — 54 теста / 1,26 с;
  host-контракт — 4 / 0,686 с; E2E артефакта — 3 / 2,88 с.
- Итого 793 теста; сумма полного времени успешных гейтов — 135,40 с.
  Время тестовых этапов взято из Vitest Duration и не включает все сборки,
  typecheck и накладные расходы команд; полный wall time включает их.
- Backend-гейт собирает все продуктовые панели и общий web host для своих E2E;
  тесты других приложений при этом не запускаются. UI-гейт собирает свою панель,
  проверяет её host-контракт и ограничивает общий E2E артефактов своей панелью.
- Первая попытка в песочнице завершилась за 68,43 с с кодом 1:
  `MachPortRendezvous: Permission denied`, 209 E2E пропущены. Она не входит
  в замер успешных гейтов и не означает дефект Reader.
- Логи и JSON-статусы лежат в `.long-runs/` с runId:
  `20260910221452254-a27e41ac-e0b1-4b11-9dbd-0879f38b3b03` (песочница),
  `20260910221626833-da96e570-546c-488d-8b79-7cfc579be1e5` (Reader),
  `20260910222012411-7af767cc-a7c0-4c41-aa6c-10fb196c19fb` (UI).
