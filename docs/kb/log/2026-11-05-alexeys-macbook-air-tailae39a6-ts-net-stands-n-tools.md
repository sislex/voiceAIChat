# stands-n-tools

## Что сделано

- `userStand {op:'git'}`: ассистент Make работает с Git в папке стенда (статус, ветки, переключение, новая ветка, коммит, diff) на машине стенда. Папка должна быть корнем репозитория, команды идут через гейт команд и замок рабочей копии.
- `userStand {op:'release'}` и `StandProxy.release`: Make сразу освобождает порт прокси удалённого или скрытого стенда, не дожидаясь часа простоя.

## Что выяснили (факты, которых не было в KB)

- Пяти портов прокси мало для бесед с несколькими стендами; для разработки рекомендуется 40 (`28810-28849`).
