# chat-exec-target

## Что сделано

- Перенесён изменяемый выбор машины с сообщений в шапку активной беседы; сайдбар показывает только машину последнего сообщения.
- Сообщения оставлены неизменяемыми снимками машины вопроса и ответа.
- Добавлены миграции SQLite, мост, тесты независимости чатов и сброс цели при удалении машины.

## Что выяснили (факты, которых не было в KB)

- `null` у цели разговора — явный выбор сервера, поэтому его нельзя объединять с legacy fallback через `??`.
- Машину чата нельзя переключать во время активного ответа: ход уже запущен со старым снимком.
