# Web Reader: однозначные действия и очередь

По уточнению пользователя завершаем текущий цикл и останавливаемся. Из списка
следующих десяти улучшений в этот цикл входят пункты 2 и 3. Ветка —
`codex/web-reader-browser-complete`, отдельный worktree `voiceAIChat1-reader-next`.
Основа актуализирована отдельным merge-коммитом `ffd7b6cf` после зелёного полного гейта.

## Изменения

- Селекторные действия исключают скрытые копии и отклоняют неоднозначную цель;
  сама операция сохраняет строгий Playwright-локатор, без `.first()`.
- `find` выдаёт ссылки на узлы документа. Перестановка сохраняет ссылку;
  клонирование/замена узла требует нового поиска. Скрытый file input разрешён
  только для upload; два file input требуют уточнения.
- Команды одного Chromium выполняются последовательно. Ошибка не ломает очередь;
  лимит — 128 запросов. Отмена удаляет ожидающие действия; начатое завершается
  перед следующим. Перезапуск закрывает контекст и прерывает зависшее действие.
- Человек берёт/возвращает управление из панели. Модель не может снять ручной
  режим, отменить очередь пользователя или выполнить в нём действие. Метаданные
  и кадры остаются доступными; состояние управления передаётся со screenshot.
- Панель считает все активные запросы: быстрый cancel не скрывает долгий запрос.
- Повторный start ждёт закрытия прежнего профиля. Гонка воспроизведена тестом:
  до исправления create вызывался при ещё не завершённом context.close.
