# c25-stand-stage4

## Что сделано

- `environment_stand.py` принимает новые настройки стенда: `VC_STAND_VPN_ADDRESS` (порты связей
  публикуются на VPN-адресе вместо 127.0.0.1), `VC_STAND_LAN_ADDRESS` (порт ядра стенда — на частном
  адресе RFC 1918), `VC_STAND_UPSTREAMS` (сервис `module-lb` на Caddy с round_robin и проверками
  здоровья для реплик модуля) и `VC_PUBLIC_HOST` + `VC_STAND_PUBLIC=1` (публичный TLS через профиль
  `public`, только для основного стенда).
- Тесты на каждую настройку и на недопустимые значения в `scripts/prod/test_environment_stands.py`.

## Что выяснили (факты, которых не было в KB)

- Адреса балансировщика подставляются в URL модулей до подстановки переменных Compose. Публичный вход
  идёт через ядро, поэтому реплики модулей получают те же маршруты.
- У воркера гейт упал без диагностики (вывод скрыт сканером секретов); у оператора полный гейт
  (`npm run gate`) на ветке поверх свежего main прошёл.

## Открытые вопросы / что осталось
