# ui-llm-access

## Что сделано

- Обновлена тема UI после CHAT-110: админская таблица персональных deny-list прав и фильтрация моделей/движков в пользовательских настройках и CI-поверхностях.

## Что выяснили (факты, которых не было в KB)

- Пустой deny-list означает полный доступ; запрет движка хранится как { provider, modelId: '*' }, запрет модели — как { provider, modelId }. Стор загружает права текущего пользователя при bootstrap через llm:access, а админские права — через отдельные load/save actions.
