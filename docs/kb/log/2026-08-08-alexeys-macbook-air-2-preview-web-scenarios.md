# preview-web-scenarios

## Что сделано

- Актуализирована KB для задачи chatai-142: запись и повторный запуск сценариев в веб-превью.

## Что выяснили (факты, которых не было в KB)

- Same-origin скрипт прокси записывает click/input шаги с CSS-селекторами, а UI воспроизводит несекретные шаги существующим протоколом DOM-действий; чувствительные значения не сохраняются и не запускаются автоматически.

## Куда занесено

- docs/kb/ui.md — «Веб-превью», подраздел «Запись и повторный запуск сценария».
- docs/kb/server-internals.md — «Прокси веб-превью».

## Открытые вопросы / что осталось

- Сценарий остаётся только состоянием открытой панели и не сохраняется в разговоре.
