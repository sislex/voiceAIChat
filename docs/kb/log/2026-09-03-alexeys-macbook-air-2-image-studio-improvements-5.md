# image-studio-improvements-5

## Что сделано

- Итерация 5: студийный контекст для хода чата (deps.studioContext в turns),
  дозагрузка галереи после спада turnActive, уборка blob-URL при размонтировании,
  персист пресета размера, авто-.png у имени генерации, двойной клик → лайтбокс,
  подтверждение «Скачать все» >10, «Использовать промпт» в лайтбоксе,
  предупреждение о квоте >80%.

## Что выяснили (факты, которых не было в KB)

- Сквозной цикл «модель рисует в чате → captureStudioImages → галерея»
  подтверждён живьём (бейдж «новое», дозагрузка после done).
- На стенде чат по умолчанию идёт через claude CLI, чей изолированный профиль
  не залогинен; для живых проверок чата студии переключали llmProvider
  на codex через PUT /api/settings.
