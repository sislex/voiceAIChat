# Веб-рекордер: восстановление DNS lookup

## Что сделано

- Закреплено продуктовое имя панели «Веб-рекордер» и описано исправленное открытие внешних сайтов через preview-прокси.

## Что выяснили (факты, которых не было в KB)

- Кастомный DNS lookup возвращал одиночный адрес при запросе Node с `all: true`, что вызывало `ERR_INVALID_IP_ADDRESS` и ответ `preview_unavailable` даже для доступных сайтов.
- Lookup теперь возвращает массив `LookupAddress` при `all: true` и один адрес в обычном режиме, предварительно отклоняя весь DNS-ответ при наличии непубличного адреса.
- Успешный ответ сохраняет статус внешнего сайта и проходит преобразование для iframe; ошибки остаются структурированными как `preview_unavailable` с понятным сообщением.
