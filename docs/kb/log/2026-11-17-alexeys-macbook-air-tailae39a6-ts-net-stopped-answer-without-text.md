# stopped-answer-without-text

## Что сделано

- На стенде с API моделей «Стоп» до первого текста ответа теперь сохраняет пустой ответ ассистента с `meta.stopped` и `meta.costPending`, чтобы пометка «Ответ остановлен… досчитывается в фоне» показывалась всегда.
- Пустой остановленный ответ не попадает в запрос следующего хода (`historyText`, `coldStartPrompt`).

## Что выяснили (факты, которых не было в KB)

- Codex через API моделей не отдаёт частичный текст: ответ приходит целиком в конце, поэтому «Стоп» почти всегда нажимается до первого текста, и раньше в ленте не оставалось ничего.
