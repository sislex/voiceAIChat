# fs2-core-file-storage

## Что сделано

- Реализован модуль Core fileStorage: SQL-метаданные, REST, конфигурация, опрос узлов и квоты.
- Подключён backend storage для загрузок чата, чтения вложений и исходников ретуши; ссылки сохраняются в истории.
- Добавлены общие контрактные проверки memory/SQL, матрица прав REST, ссылки, квоты, пул узлов и перезапуск Core.

## Что выяснили (факты, которых не было в KB)

- Метаданные используют общий SQL-адаптер Core; обновление строки блокировки предшествует чтению квоты и ревизии.
- Аутентификация Core завершается в preHandler: проверки storage должны выполняться после неё.
- Существующее JSON-хранение MessageAttachment сохраняет поле storage без отдельной миграции сообщений.
