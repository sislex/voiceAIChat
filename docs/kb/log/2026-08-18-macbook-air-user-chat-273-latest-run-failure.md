# chat-273-latest-run-failure

## Что сделано

- Добавлен серверный нормализованный результат последнего workflow-рана задачи и доступная красная подсветка карточки.
- Старт и завершение ранов обновляют карточку через `board.update`; предупреждение ведёт на вкладку соответствующего этапа.

## Что выяснили (факты, которых не было в KB)

- `cancelled` является нейтральным результатом и не подсвечивает карточку; неизвестный терминальный серверный статус считается ошибкой.
- При одинаковом времени создания активный ран должен вытеснять терминальный результат, чтобы подтверждённый retry сразу очищал рамку.
