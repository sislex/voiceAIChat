# chat-space-titles-local-date

## Что сделано

- Старые пространства бесед с именем «Chat files» переименовываются в название беседы при первом показе списка пространств (`GET /api/storage/spaces`).
- Папка вложений `YYYY-MM-DD` считается по часовому поясу сервера, а не по UTC; публичный стек задаёт Core `TZ` из `PUBLIC_TIME_ZONE` (по умолчанию Europe/Minsk).

## Что выяснили (факты, которых не было в KB)

- Синхронизация названий шла только при загрузке и переименовании, поэтому пространства, созданные до неё, так и показывались как «Chat files · Владелец».
- Контейнер Core работает в UTC: файл, отправленный ночью по Минску, попадал в папку предыдущего дня.

## Куда занесено

- docs/kb/server-internals.md (жизненный цикл пространства беседы)

## Открытые вопросы / что осталось

- Время ответа модели в истории (`time`) сервер тоже пишет по своему поясу; на проде (UTC) оно расходится с временем сообщения пользователя. В интерфейсе это поле не показывается.
