# done-order

## Что сделано

- Дополнена тема проектов правилом порядка карточек в Done.

## Что выяснили (факты, которых не было в KB)

- Done сортируется по убыванию `doneAt`, а не по `updatedAt`; у старых строк без метки fallback — `position`, `createdAt`, `id`.
