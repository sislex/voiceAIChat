# prod-rebuild-followup-task

## Что сделано

- Финализация успешного CI-рана заводит автозадачу учёта «Пересборка прода»,
  если ветка влита в прод-ветку (успешный `isMergeToBaseStep`), а успешного шага
  пересборки прода в ране не было: изменения в прод-ветке есть, до прода не
  доехали. Саму пересборку не запускаем — это решение человека.
- `isProdRebuildStep` (`ci/runManager.ts`) — детектор шага пересборки по
  назначению: название про прод + обновление/пересборку либо `docker compose up
  --build` / `npm run docker` в снапшоте скрипта (боевая команда «Обновить
  прод-контейнер» подходит по обоим признакам).
- `VoiceChatDb.ensureProdRebuildTask` — идемпотентная запись в транзакции: одна
  открытая (не в done-колонке) карточка «Пересборка прода» на проект, описание —
  список строк `- KEY-N: заголовок`, повтор той же строки ничего не меняет.
- Юнит-тесты на `:memory:`: `runManager.test.ts` (два рана → одна карточка с
  двумя строками, повтор рана без дублей, успешная пересборка → карточки нет,
  ран без мержа → карточки нет, карточка в done → заводится новая) и
  `database.ci.test.ts` (накопление строк, done-карточка, нет колонки `ready`,
  не участник проекта).

## Что выяснили (факты, которых не было в KB)

- Прод-ветка и пересборка прода в раннере — разные шаги одного слота «после»:
  мерж (`git merge` в рабочей копии задачи) и «Обновить прод-контейнер», который
  тянет прод-репозиторий и запускает `docker compose up --build -d` отложенным
  `setsid` (пересборка убивает контейнер самого раннера). Поэтому пачку ранов
  гоняют без шага пересборки, и учёт «что осталось выкатить» нужен отдельно.
- Отсутствие колонки в тестах БД эмулируется подменой `getColumnIdBySemantic`:
  `deleteColumn` не удаляет колонки с не-`custom` semantic type.

## Куда занесено

## Открытые вопросы / что осталось

- Прод-контейнер по условиям задачи не пересобирался: на боевой доске автозадача
  появится после следующего деплоя.
- Карточку «Пересборка прода» никто не закрывает автоматически: после ручной
  пересборки её двигают в done руками, и следующий мерж заведёт новую.
