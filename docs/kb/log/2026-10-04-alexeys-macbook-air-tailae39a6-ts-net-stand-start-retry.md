# stand-start-retry

## Что сделано

- Шаг `start` скрипта стенда повторяет `compose up` (до трёх раз, пауза 5 с) при `address already in use`.
- Упавшая команда стенда передаёт хвост вывода (значения настроек скрыты) в `log` события `failed`.

## Что выяснили (факты, которых не было в KB)

- U04: на M1 (Docker Desktop, macOS) пересоздание `voicechat`, опубликованного на VPN-адрес
  100.126.46.22, падало с `failed to bind host port 127.0.0.1:55040/tcp: address already in use` —
  вспомогательный порт Docker Desktop старого контейнера освобождается с задержкой; повтор проходит.
- Скрипт стенда берётся из checkout ядра версии конфигурации окружения: исправление скрипта действует
  после перевода конфигурации на новое ядро.
