# Вид доски на сервере, версия релиза и тема по человеку

## Что сделано

Шесть задач одним заходом (продолжение работы «настройки переживают деплой»):

1. **Вид доски переехал на сервер** — таблица `board_views`, роуты
   `GET/PUT /api/projects/:id/board/view`, `sanitizeBoardView` в `@shared/projects`,
   состояние `boardView` в `projectsStore`, пропсы `view`/`onViewChange` у
   `KanbanBoard`, разовый перенос прежней записи из предпочтений браузера.
2. **Расхождение версий видно**: `app:ping` повторяется на каждом переподключении
   WS, изменившийся `version@commit` показывает предложение обновить страницу.
3. **CI и удалённый движок**: правка «забывать движок при чтении» откачена —
   она ломала наследование этапов (поймал тест); вместо неё зафиксировано
   тестом реальное поведение `resolveLlmEngine` (подмена доступным исполнителем).
4. **Дефолты фиксируются в записи**: `getSettings` дозаполняет отсутствующие
   поля и сохраняет их, поэтому «поле появилось в релизе» отличимо от
   «человек выбрал это значение».
5. **E2E в реальном Chromium** — `e2e/settings.e2e.test.ts` (`npm run e2e:settings`):
   тема сохраняется и переживает перезагрузку; при упавшем сервере изменение
   откатывается, а запись цела; вернувшийся сервер подхватывается без
   перезагрузки страницы.
6. **Тема по человеку**: `vc.theme.<логин>` плюс общий `vc.theme` для экрана
   входа; `hydrateThemeFor` вызывается на `session.authenticated`.

## Что выяснили (факты, которых не было в KB)

- `pkill -f "vite"` убивает и работающий `vitest` — гейт завершается кодом 143.
  Гасить стенд нужно точечно (по порту/PID), а не по маске.
- В e2e кнопка меню аккаунта подписана логином (`admin`), а не ролью; вход в
  Playwright делается через `localStorage['vc.session.token']`, как в
  `projects.e2e.test.ts`.
- Фиксацию дефолтов нельзя проверить через REST-тест: у `VoiceChatDb` нет
  публичного доступа к сырому соединению — тест живёт на файловой БД в
  `db/database.test.ts`.

## Открытые вопросы / что осталось

- Баннер новой версии пришлось дважды переносить: сначала перекрывал шапку,
  потом панель фильтров. Итог — внизу справа, как тост.
- Вид доски пока не синхронизируется между вкладками живьём: соседняя вкладка
  увидит изменение только при следующем открытии доски.
