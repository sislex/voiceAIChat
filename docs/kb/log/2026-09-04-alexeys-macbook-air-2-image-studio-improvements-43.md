# image-studio-improvements-43

## Что сделано

- Итерация 43: вынос блока публикации в `ImageStudioShareBar.tsx`;
  клавиатурный доступ к контекстному меню; наложение (difference) в
  сравнении; группировка сетки по датам; валидация имени до запроса;
  пакетное копирование в другой чат; «Промпты выбранных»; серия из трёх
  вариаций; чипы частых запретов у негативного промпта; фильтр
  «С прошлого визита».

## Что выяснили (факты, которых не было в KB)

- Контекстное меню внутри панели обязано гасить всплытие клавиш навигации:
  стрелка доходила до корневого обработчика сетки, тот двигал выбор и уводил
  фокус на превью. Dom-тест это пропускал — корневой обработчик доводит фокус
  через `setTimeout`, которого в тесте не дождались. Проверять такие вещи
  надёжнее в браузере, а в тесте стоит дополнительно утверждать, что выбор
  карточки не сменился.
- Сессия веб-клиента живёт в HttpOnly-cookie, а мутации подписываются
  заголовком `x-vc-csrf` из читаемой cookie `vc_csrf` (`remote/session.ts`).
  Для ручной уборки через API из консоли браузера нужен именно этот заголовок:
  с `x-csrf-token` сервер отвечает 403 `csrf`.
- Тулбар фильтров (а с ним корзина и её очистка) показывается только при двух
  и более файлах в галерее — в чате с одним файлом убирать корзину через UI
  нечем.
