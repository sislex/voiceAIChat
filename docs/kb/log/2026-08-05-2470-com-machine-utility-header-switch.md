# machine-utility-header-switch

## Что сделано

- Общая шапка `MachineUtilityHeader` для `MachineConsole`/`MachineTerminal`/`FileExplorer`:
  машина со статусом видна всегда (не только при agents.length > 1), бейджи
  запретов политики с подсказками, двусторонний переключатель «консоль/терминал
  ↔ проводник» и ссылка «Машины ↗».
- `store.openUtility` получил 4-й параметр `dir`: без него path трактуется как
  файл (открывается родитель), с `dir=true` — как папка (открывается внутри).

## Что выяснили (факты, которых не было в KB)

- До задачи шапки каждого из трёх виджетов рисовали свой `.fsbar`, селектор машины
  показывался только при `agents.length > 1` — при одной машине пользователь не
  видел, где работает; переход между утилитами был только в одну сторону
  (проводник → терминал).
- Теперь переход двусторонний и не теряет папку: проводник отдаёт `cwd` последнего
  `fs.list`, терминал/консоль — `initialCwd`; машина всегда та, что выбрана в
  селекторе шапки, а не «первая онлайн».
