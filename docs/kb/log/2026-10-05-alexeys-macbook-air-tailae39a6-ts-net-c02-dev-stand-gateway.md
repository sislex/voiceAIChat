# c02-dev-stand-gateway

## Что сделано

- Шлюз стенда разработки `npm run dev:gateway` (dev-lane-v1 C02): префиксы компонентов из `DEV_COMPONENT_REGISTRY` идут в процесс из ветки по составу стенда, остальное — в базовый стенд; WebSocket и SSE; состав перечитывается без перезапуска; по умолчанию слушает `0.0.0.0` (домашняя сеть и Tailscale).
- `npm run dev:component` для сервера ядра: `tsx watch` с данными копии стенда и адресами остальных компонентов через `SISLEXA_STAND_URL`.
- Сборка релиза, проверка закреплений и сверка рендерера Desktop отклоняют версии `<версия>-dev.<sha12>`.
- REST стендов проекта ядро передаёт в Kanban.

## Что выяснили (факты, которых не было в KB)

- Гейт воркера на новой версии Delivery Control прошёл в попытке; тесты шлюза, которым нужен сетевой порт и `tar`, песочница по-прежнему не запускает.
