# stopped-run-not-found

## Что сделано

- Остановленный ответ на стенде с API моделей больше не висит с пометкой «досчитывается» навсегда, если прод не знает ран: Core снимает пометку (`costPending: false`) без стоимости.

## Что выяснили (факты, которых не было в KB)

- Прод отвечает `run_not_found` на `GET /v1/run/:id`, если «Стоп» пришёл до допуска рана в учёт: записи в учёте нет, списания нет. Раньше стенд на этом прекращал опрос и пометка оставалась навсегда (проверка на проде 22.11, ран остановлен через 0,5 с).
