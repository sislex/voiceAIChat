# Перекомпоновка шапки/подвала ответа в чате

Правки `ChatColumn` по запросу пользователя:

- **Копировать ответ** перенесена из шапки внутрь пузыря `.bub` (класс `.copymsg`),
  той же иконкой `⧉`/`✓` и в том же углу, что копия кода `.copycode`; проявляется
  по ховеру пузыря (`.ai .bub` получила `position: relative`).
- **Машина выполнения** теперь в шапке `.msg-head` сразу за движком/моделью
  (`.msg-machine-head`), а не в подвале. У стримящейся и preparing-карточки — так же.
- Из подвала убраны машина (`.msg-machine`), режим ответа (`.msg-mode`) и отдельная
  стоимость (`.msg-cost`) — CSS-правила удалены.
- **Стоимость** ушла в блок токенов `.msgact-tokens` (`.msgact-cost`) и продублирована
  строкой в тултипе/модалке `MessageMeta` (через общий `messageCost`; расчётная
  помечается «(расчётная)»).
- Время сверху (начало) и снизу (конец) — оба `clockTime` в формате ЧЧ:ММ:СС и оба
  крайние правые (снизу — в `.mfoot-right` с `margin-left:auto`, порядок озвучить →
  удалить → время).
- «Готовим ответ…» теперь показывается внутри `.bub` полноценной карточки ответа
  (шапка со сведениями видна сразу); внешний контейнер сохраняет
  `data-testid="reply-preparing"`.

Тесты `ChatColumn.dom.test.tsx` обновлены (машина в шапке, время ЧЧ:ММ:СС,
структура preparing-карточки); тест про режим ответа в подвале удалён. Гейты
зелёные: ui typecheck/test (1786), web build, storybook build.
