# Подготовка PR отдельного приложения студии картинок

## Что сделано

- По запросу пользователя подготовлена ветка `feat/image-studio-standalone` от актуального `origin/main` (`c8fcb5e8`). В неё входят пакет студии, адаптеры ядра, контракт shared, Docker/Caddy, тесты и тематическая KB.
- Перед коммитом пройден полный `npm run gate` с кодом 0: typecheck всех workspaces, 7506 успешных Vitest-тестов, корневые тесты скриптов, сборки web и Storybook. Повторный fetch подтвердил актуальность базы PR.
- Конфигурация Compose прошла `VC_PUBLIC_HOST=127.0.0.1 docker compose config --quiet`; проверены внутренний API, общий токен и пути старых галерей.

## Что выяснили (факты, которых не было в KB)

- Проверка PR подтвердила уже описанные границы приложения; новых изменений поведения после синхронизации с main не потребовалось.

## Куда занесено

- Описание архитектуры и запуска идёт в этом же коммите: `server-internals.md`, `deploy.md`, `protocol.md`, `shared.md`, `ui.md`, `testing-operations.md` и AGENTS пакетов.

## Открытые вопросы / что осталось

- Проверка использует фейковый LLM. Docker-образ и production в этом шаге не запускались.
