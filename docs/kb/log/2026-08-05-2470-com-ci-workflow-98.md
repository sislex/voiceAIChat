# ci-workflow-98

## Что сделано

- Проверен и приведён к исполнимому порядку проектный CI-пайплайн ChatAI: clone → npm ci → affected-check → БЗ → commit → push → merge → прод → cleanup.
- В боевой записи команды «Обновить прод-контейнер» `PROD_REBUILD_DELAY` увеличен с 180 до 1600 секунд.

## Что выяснили (факты, которых не было в KB)

- Задержка пересборки должна покрывать не только cleanup и резюме, но и оставшиеся после модельного хода гейт, commit, push и merge; 180 секунд для этого недостаточно.
