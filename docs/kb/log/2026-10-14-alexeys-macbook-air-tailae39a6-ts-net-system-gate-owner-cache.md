# system-gate-owner-cache

## Что сделано

- Чекауты владельцев системного гейта перенесены из `.cache/system-owners` внутри Core в `~/.cache/sislexa/system-owners/<хэш чекаута>` (переопределение — `SISLEXA_SYSTEM_OWNERS_DIR`).
- Core-фикстура владельца засевается из локального чекаута Core, остатки прерванного fetch чистятся.

## Что выяснили (факты, которых не было в KB)

- Защита рабочей директории задач канбана запрещает вложенные git-репозитории: чекауты владельцев внутри репозитория задачи роняли подготовку и отправку ветки с кодом 66.
- Неглубокая загрузка Core с GitHub (~135 МБ) на медленной сети обрывалась по таймауту и оставляла `shallow.lock`.
