# feature-preview-docker-preflight

## Что сделано

- Убрана прямая зависимость кнопки запуска preview от `crypto.randomUUID`.
- Перед build/start добавлен preflight наличия Docker CLI и готовности Docker Engine.
- Ошибка удалённой команды теперь сохраняет последнюю содержательную строку вывода.
- Добавлены регрессионные тесты UI и manager; typecheck и затронутые тесты зелёные.

## Что выяснили (факты, которых не было в KB)

- Feature-preview использует workspace последнего CI-рана и пока не поддерживает выбор другой машины.
- До preflight ненулевой exit code скрывал причину отказа Docker.

## Куда занесено

- `docs/kb/features/feature-preview.md`.

## Дополнительная реализация

- Добавлен выбор машины проекта; для другой машины создаётся отдельная preview-копия feature-ветки.
- Добавлены явные операции запуска и подтверждаемой установки Docker.
- Healthy-состояние preview сохраняется в задаче и включает зелёную пульсацию карточки.
- Добавлена системная колонка `qa_preparation`, форма подробных сценариев и серверный gate перехода в `manual_qa`.

## Открытые вопросы / что осталось

- Автоматическая установка требует Homebrew на macOS либо apt и заранее настроенный беспарольный sudo на Linux; остальные платформы получают явное сообщение о неподдерживаемой операции.
