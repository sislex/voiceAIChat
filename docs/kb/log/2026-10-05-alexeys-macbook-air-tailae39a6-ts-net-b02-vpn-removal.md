# b02-vpn-removal

## Что сделано

- Снятие VPN-доступа окружения (reliability-v2 B02): сначала с устройств снимается тег окружения, затем пишется политика без его `tagOwners` и правил.
- Устройство не остаётся без тегов: ставится базовый тег привязки, если у него есть владелец в политике, иначе — ошибка `vpn_untag_requires_reauth` с именем устройства.
- Неудачное снятие оставляет фазу `removing`, его можно повторить. Другие VPN-операции эта фаза не блокирует. Повторная выдача того же окружения ждёт завершения снятия.
- Ошибки Tailscale API превращаются в коды `VpnError` с очищенным сообщением в журнале операции и проходят через RPC как HTTP 409 вместо 500.
- Состояние доступа показывает устройства, на которых тег ещё стоит.

## Что выяснили (факты, которых не было в KB)

- Раньше при снятии политика без владельца тега писалась до снятия тега с устройств, а внутренний RPC превращал любую `VpnError` в `RPC_HTTP_500` без причины.
