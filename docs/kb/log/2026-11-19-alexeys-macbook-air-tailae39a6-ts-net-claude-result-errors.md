# claude-result-errors

## Что сделано

- `parseStreamJsonLine` берёт текст неудачного `result` из списка `errors`, когда поля `result` нет.
- Ответ 429 `concurrency_limit_exceeded` от API моделей показывается пользователю понятным текстом (`MODEL_API_BUSY_MESSAGE`).

## Что выяснили (факты, которых не было в KB)

- Claude Code 2.1.326 при `--resume` несуществующей сессии отдаёт `result` с `subtype: error_during_execution` и причиной только в `errors`. Ход Make на стенде после перехода с текстового пути на транзит падал с «Claude вернул ошибку»: в беседе осталась сессия текстового запуска, которая на раннере не сохраняется, а повтор в новом треде не срабатывал — текст причины терялся.
- API моделей ограничивает одновременные запуски (по умолчанию 4); два стенда с одним токеном делят этот лимит.

## Открытые вопросы / что осталось

- Лимит одновременных запусков API моделей не настраивается через окружение прода.
