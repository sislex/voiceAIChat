# account-logout

## Что сделано

- Актуализировано описание пользовательских сессий и штатного выхода из ChatAI.

## Что выяснили (факты, которых не было в KB)

- Каждый вход выпускает уникальный Bearer-токен; logout отзывает только его через постоянный SQLite deny-list.
- Клиент очищает локальный токен и переподключает WebSocket только после успешного серверного logout.
- Выход не затрагивает данные пользователя и авторизацию внешних CLI-сервисов.
