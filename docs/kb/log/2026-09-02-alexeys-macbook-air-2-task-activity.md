# Активность карточки как в Jira: комментарии, ворклог, история

Новая функция по запросу пользователя. Вкладка «Активность» в карточке задачи:
комментарии (CRUD человеком и моделью канбан-ассистента), история изменений
полей (пишет сервер сам в updateTask/moveTask), ворклог с итогом минут.

Ключевые решения:
- членство в проекте — граница видимости, роль — граница модерации: чужой
  комментарий правит автор, владелец проекта или админ-участник;
- удаление комментария моделью необратимо → подтверждение даже при полной
  автономии (как деплой);
- порядок лент в SQLite — по rowid, не по id: uuid в ORDER BY id даёт
  случайный порядок при равных временных метках;
- перестановка карточки внутри колонки историю не пишет — этап не изменился.

Проверено: 8 тестов БД, 2 роутовых, 1 MCP (включая подтверждение удаления),
4 dom-теста панели; живой стенд по API — комментарий с пометкой «изменён»,
история title/priority, ворклог 135 минут. Браузерная визуальная проверка не
выполнена: расширение Chrome отключилось (браузер закрыт) — поведение панели
покрыто dom-тестами, встройка вкладки повторяет паттерн «Временной шкалы».
