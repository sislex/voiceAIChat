# c03-quick-gate

## Что сделано

- `npm run gate:quick -- --base <sha>`: планировщик приложений ядра, для каждого выбранного приложения —
  проверка типов, сборка и vitest только для изменённых тестов и связанных с изменёнными исходниками;
  инструменты — по графу импортов node:test; неизвестные изменения корня/конфигов/lock — полный гейт.
- `npm run test:files -- <files>`: запуск заданных тестовых файлов своим раннером; при сбое оба печатают
  `GATE-FAILED-TESTS: <json>`.

## Что выяснили (факты, которых не было в KB)

- Проверка оператора: правка одного файла сервера — `gate:quick` за 30 с (типы, сборка, 392 связанных
  теста) против ~4 мин полного гейта; `test:files` на падающем тесте печатает его в `GATE-FAILED-TESTS`.
- В песочнице модели воркера git получает EPERM, и `gate:quick` безопасно откатывается на полный гейт.

## Куда занесено

- docs/kb/testing-operations.md — команды быстрого гейта; AGENTS.md — список команд.

## Открытые вопросы / что осталось

- Проверить, что в песочнице гейта супервизора git доступен; иначе быстрый гейт у воркера всегда полный.
