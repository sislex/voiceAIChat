# public-gallery-search

## Что сделано

Итерация 67 студии картинок (9 пунктов): на публичной странице галереи
появился поиск по имени (от 12 файлов, фильтрация без запросов), счётчик
найденного, общий вес галереи в заголовке, `main` вместо `div` у сетки и
`role="search"` у поля. Два серверных теста: поиск есть от дюжины файлов и
его нет у маленькой галереи.

## Что выяснили (факты, которых не было в KB)

- Публичная страница — единственное место продукта, где интерфейс собирается
  строкой HTML со встроенным `<script>`: React там нет вовсе, поэтому фильтр
  написан ванильным JS и живёт прямо в шаблоне.
- Порог в 12 файлов выбран, чтобы у типичной галереи на 3–5 кадров не
  появлялось лишнее поле: скрипт и разметка добавляются только при
  `files.length >= 12`.
- Проверено в браузере: 90 карточек фильтруются до 10 по «кадр-01», счётчик
  показывает «Найдено: 10», очистка поля возвращает все.

## Открытые вопросы / что осталось

- «Скачать всё» для зрителя так и нет: ZIP на публичной странице пришлось бы
  собирать в браузере (в приватной части архив собирает клиент). Кандидат на
  отдельную задачу, если понадобится.
