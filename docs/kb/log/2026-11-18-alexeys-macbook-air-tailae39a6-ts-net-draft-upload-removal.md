# draft-upload-removal

## Что сделано

- Маршрут `DELETE /api/uploads/:id`: вложение, убранное из неотправленного черновика, удаляется из хранилища (или с сервера/машины) вместе с записью загрузки. Только владелец; если файл уже используется сообщением беседы — 409 `upload_in_use`.
- `db.chat.conversationAttachments` — вложения всех сообщений беседы в любом состоянии и ветке.

## Что выяснили (факты, которых не было в KB)

- Записи загрузок (`UploadStore`) живут в памяти процесса: после перезапуска Core файл брошенного черновика остаётся в пространстве беседы до удаления через панель «Файлы» или вместе с беседой.
- Автоуборки непривязанных файлов нет намеренно: в пространстве беседы могут лежать файлы, положенные пользователем через панель хранилища.
