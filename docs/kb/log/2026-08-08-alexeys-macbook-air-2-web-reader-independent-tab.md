# Web Reader: независимая вкладка

## Что сделано

- Дополнена UI-тема фактическим способом открытия самостоятельного рабочего пространства Web Reader.

## Что выяснили (факты, которых не было в KB)

- Пункт сайдбара открывает `#/web-reader` в новой вкладке с `noopener,noreferrer`, не меняя маршрут исходного чата.
- Новая вкладка самостоятельно выбирает Reader-разговор и монтирует общий `ChatColumn` рядом с `WebReaderHost`; исходная страница второй чат не получает.
