# ci-run-terminal-reason

## Что сделано

- Дополнена тема CI-раннера описанием сохранения и показа причины терминального рана без шагов.

## Что выяснили (факты, которых не было в KB)

- `ci_runs.error` проходит через `CiRun` и `CiRunSummary`; failed без диагностики получает безопасный текст, а известные предстаровые отказы и рестарт сервера сохраняют конкретную причину.
- Терминальная лента без шагов показывает причину вместо empty state, карточка задачи — короткий текст в CI-блоке.

## Куда занесено
