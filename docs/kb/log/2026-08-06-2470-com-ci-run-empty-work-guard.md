# Пустой ход модели больше не закрывает ран успехом

## Что сделано

- `remotePath` (`apps/server/src/mcp/remoteBashMcp.ts`) принимает абсолютный путь
  внутри `cwd`; путь вне `cwd` отвергается сообщением, где назван сам `cwd`.
- Раннер после успешного модельного хода вставляет системный шаг «Проверка
  результата модели» (`ensureModelProducedWork`): нет коммитов сверх
  `$BASE_BRANCH` и нет изменений, а вызовы инструментов у рана были — слот
  «после» пропускается целиком, рабочая копия сохраняется, карточка остаётся в
  рабочей колонке, ран `failed`, причина уходит в резюме чата.
- Быстрый этап `affected-check` зовёт `npx vitest related` в папке пакета вместо
  несуществующей опции `vitest run --related`.
- Поправлена протухшая проверка промпта в `ci/modelHooks.test.ts` (осталась от
  времён, когда модель не запускала проверки сама).

## Что выяснили (факты, которых не было в KB)

- `vitest run --related` в vitest 2.1.9 падает с «Unknown option `--related`»:
  `related` — это подкоманда (`cli.command("related [...filters]")`), а тестовый
  скрипт каждого пакета — `vitest run`. Быстрый этап гейта падал на любой правке
  кода.
- В ране гейт этого не показывал: шаг «Запустить проверки затронутых пакетов»
  писал в ленту только заголовок npm (78 символов) — вывода самого
  `affected-check.mjs` в логе шага нет.
- Ран `d2ba80bc` (CHAT-108) прошёл все 14 шагов с нулевыми кодами, не создав ни
  одной правки: коммит при пустом индексе выходит с `0`, мерж — `Already up to
  date`, пересборка — «прод-репозиторий на 24bd145», cleanup удалил клон.
  Модель при этом прямо написала, что работу не выдаёт.

## Куда занесено

- docs/kb/features/ci-runner.md — раздел «Пустой ход модели не может закончиться
  успехом».
- docs/kb/llm.md — абзац «Абсолютные пути внутри `cwd` разрешены» в разделе
  «Проброс Bash на машину пользователя».

## Открытые вопросы / что осталось

- Шаг «Запустить проверки затронутых пакетов» теряет stdout `affected-check.mjs`
  в ленте рана — причина не найдена.
- Исходный объём CHAT-108 (живой таймер ленты, сброс `workdir` чата после
  cleanup, строка резюме БЗ, `--silent` в test-скриптах) не сделан.
