# chat-202-kb-usage-disclosure

## Что сделано

Сведения об использовании БЗ в development- и merge-лентах представлены компактными disclosure-строками. Для development-рана строка раскрывает сводку, использованные разделы, отдельные события и ошибки; для merge-рана отдельно показывает состояние стадии актуализации `kb_update`.

## Что выяснили (факты, которых не было в KB)

`KbUsageBrief` теперь является доступным accordion: управляющая строка — кнопка с `aria-expanded` и `aria-controls`, `Esc` сворачивает панель и возвращает фокус. `useRemoteReport` сбрасывает отчёт при смене ключа рана, игнорирует устаревший ответ через cleanup эффекта и предоставляет повторную загрузку с сохранением уже известного отчёта при ошибке обновления.
