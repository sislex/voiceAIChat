# ui-settings-routes

## Что сделано

- Актуализирована документация hash-маршрутов общих настроек и границы LLM-настроек разговора.

## Что выяснили (факты, которых не было в KB)

- Все вкладки общих настроек имеют адрес `#/settings/:section`; старый неразделённый `#/settings` заменяется на `#/settings/llm` без новой записи истории.
- Форма разговора больше не редактирует LLM engine/provider/model и при сохранении сохраняет прежние legacy-переопределения без изменений.
