# image-studio-tint-loop

## Что сделано

Итерация 64 студии картинок (10 пунктов, из них 4 — вокруг одного серьёзного
дефекта): порядок «По цвету» больше не зацикливает панель, у счёта цветов
появился индикатор, неудачные кадры не пересчитываются. Плюс два теста и четыре
проверки без находок (виртуализация, размер страницы, поиск по 88 файлам,
lazy-загрузка).

## Что выяснили (факты, которых не было в KB)

- **`ensureTints` зовут прямо из тела рендера.** Пока внутри не было `setState`,
  повторные попытки посчитать «непосчитываемые» кадры (svg, битые, отозванный
  blob) оставались незаметными. Индикатор прогресса сам вызывает рендер — и
  получился вечный цикл: renderer в Chrome не отвечал 45 с, а прогон
  dom-тестов студии вставал намертво (vitest висел >7 минут без вывода).
  Лечение: множество `tintFailed` + `setState` только в микротаске.
- **`setState` в фазе рендера** (а не в эффекте/микротаске) React крутит по
  кругу — в тестах это выглядит как зависший прогон, без единой ошибки в логе.
- **`loading="lazy"` не грузит превью в скрытой вкладке.** Проверки через CDP
  идут при `document.hidden === true`, поэтому «ни одна картинка не загрузилась»
  — артефакт проверки, а не дефект: снимаешь атрибут — картинка грузится.
- Проверки без находок: виртуализация работает (при 88 файлах в DOM 60 карточек
  плюс спейсер), выбор «Карточек на странице: 300» убирает «Показать ещё» и
  отдаёт всю галерею, поиск по 88 файлам укладывается в секунду.

## Открытые вопросы / что осталось

- Индикатор прогресса глазами в браузере не пойман: в скрытой вкладке счёт
  идёт медленно и таймеры троттлятся — стоит посмотреть при активном окне.
