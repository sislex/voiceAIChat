# image-studio-improvements-53

## Что сделано

- Итерация 53 (тридцать пунктов): журнал операций с отменой, модуль
  `lib/imageFacts.ts` (тип по сигнатуре, расхождение расширения,
  прозрачность, число цветов, дерево версий, заметки в Markdown), факты и
  дерево версий в свойствах лайтбокса, «Показать в сетке», фокус на соседа
  после удаления, объявление размера выбора, мигание карточки после
  автопрокрутки, крестик и Esc в поиске, фильтр «За сутки», `⌘F` и `⌘A`,
  «Ещё раз» для обработки, «Выбрать группу», звук по концу пакета,
  сворачивание панели рисования, «Список файлом», «Заметки в буфер», печать
  контактного листа, чип набора «живых из всех» с чисткой, освобождение
  blob-URL превью пропавших файлов, узкая лента кадров на телефоне.

## Что выяснили (факты, которых не было в KB)

- **Dev-витрина и `npm run gate` вместе не живут**: гейт собирает
  `storybook-static`, dev-сервер видит запись в свой каталог и уходит в цикл
  перезагрузок, отдавая пустую страницу. Сначала гейт, потом витрина.
- Сосед для фокуса после удаления берётся **до** запроса: после перезагрузки
  списка индексы уже другие, а без этого фокус улетал в `body`.
- Строку «Выбрано N из M» (`role="status"`) читалка проглатывает — она
  перерисовывается на каждый клик. Нужно отдельное объявление с задержкой,
  когда выбор устоялся.
- Blob-URL превью надо отзывать при исчезновении файла из списка: иначе
  память вкладки растёт до перезагрузки (десятки мегабайт на сотне обработок).
- Долгие `await` в скриптах браузерной проверки ловят таймаут CDP (45 с),
  когда машина занята гейтом: измерять надо короткими вызовами, а не одним
  длинным сценарием.
