# user-message-copy

## Что сделано

- Актуализирована тема UI по кнопке копирования сохранённых пользовательских сообщений.

## Что выяснили (факты, которых не было в KB)

- Вопрос и ответ используют общий `copyMessage`, копирующий исходный `Message.text`; подтверждение появляется только после успешного `copyText`.
- Кнопка вопроса постоянно видима, доступна с клавиатуры и имеет отдельные состояния для светлой и тёмной тем без нарушения мобильной раскладки.
