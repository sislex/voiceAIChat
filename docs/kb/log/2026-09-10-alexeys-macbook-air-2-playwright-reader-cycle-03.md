# Playwright Reader — цикл 03, действия модели и формы

## Что сделано

Десять пунктов: модификаторы клика, селектор клавиши, вложенная прокрутка,
настоящий край длинной страницы, сохранение высоты viewport, drag по координатам,
контекст страницы в ответе, пустой файл, строгий base64, сквозной лимит upload 8 МиБ.
Общий лимит JSON для команд — 16 МиБ, остальные HTTP-роуты не расширялись.

## Что выяснили

Восемь исходных Chromium-регрессий упали; две гипотезы (select по подписи и range)
оказались уже работающими и не считаются исправлениями. Дополнительные регрессии
viewport и drag тоже воспроизведены. После исправлений: 38 тестов раннера, включая
12 живых, и 46 адресных shared прошли. Первый E2E: 6/6, в том числе настоящий MCP
выбрал в Chromium файл 8 МиБ. Повтор после пересборки web прошёл 6/6. Финальная проверка с упорядоченным закрытием
стенда — 53,10 с, сами шесть сценариев — 10,19 с. Ускорение стенда не заявляется:
параллельная нагрузка менялась.

гейт: exit 0, 7269 passed / 45 skipped, 506,50 с при двух воркерах. Таймаут
реальной загрузки 8 МиБ из параллельного прогона не повторился; тест не ослаблялся.
Первый быстрый гейт обнаружил
старое ожидание wheel в scenarioStep.test.ts; оно обновлено под selector scroll.
