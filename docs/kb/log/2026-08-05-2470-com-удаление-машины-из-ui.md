# удаление-машины-из-ui

## Что сделано

- В таблицу «Машины» (`MachineStatus.tsx`) добавлено удаление машины: корзина →
  раскрытая строка-подтверждение («Удалить»/«Отмена»), тот же приём, что у
  удаления файла в `FileExplorer`. Проп `onDeleteAgent`, проброшен из
  `App.tsx` как `actions.deleteAgent`.
- `AgentCard.tsx` перестал быть отдельной несмонтированной карточкой (была
  подключена только в сториз) и стал редактором политики строки: раскрывается
  стрелкой «▸» в столбце «Машина», без своей шапки/сворачивания/токена/удаления
  — это всё теперь у строки таблицы. Правки (`allowedDirs`, `denyPatterns`,
  `allowPatterns`, `skills`) уходят сразу через `onSetPolicy`, черновик и кнопка
  «Сохранить» убраны.
- `db.deleteAgent` (`apps/server/src/db/database.ts`) стал дополнительно
  чистить `projects.default_agent_id` — раньше эта колонка (без FK) оставалась
  висеть на удалённую машину. Роут `DELETE /api/agents/:id` сбрасывает
  `settings.defaultAgentId` (не только `execTarget`, как раньше). Стор
  повторяет оба сброса в клиентском состоянии.
- Обновлены `docs/kb/machines.md`, `docs/kb/ui.md`, `docs/kb/projects.md`,
  `packages/ui/AGENTS.md`.

## Что выяснили (факты, которых не было в KB)

- До этой задачи удаления машины в UI не было вообще: кнопка жила в
  `AgentCard.tsx`, который грепом по репо нигде не рендерился — только в
  сториз.
- Редактора `allowedDirs`/`denyPatterns`/`allowPatterns`/`skills` на web тоже
  не было нигде подключено. Второй, независимый редактор политики существует в
  трей-приложении (`apps/agent-tray/src/renderer/permissions.ts`) — это
  отдельный код, web его не переиспользует.
- `projects.default_agent_id` — колонка без внешнего ключа; CASCADE в
  `project_machines` её не касается. `runManager.ts:226` и `:872` берут
  `project.defaultAgentId` для старта CI-рана, `database.ts:2141` — для
  контекста чата задачи. Без явной чистки удаление машины оставляло проекту
  дефолт на несуществующего агента.

## Куда занесено

- docs/kb/machines.md — раздел «Подключение и жизненный цикл» (удаление и что
  чистится) и «Политика команд» (где теперь редактируется policy).
- docs/kb/ui.md — абзац про `MachineStatus`/`AgentCard`.
- docs/kb/projects.md — раздел «Папка на машину, машина по умолчанию…»
  дополнен фактом про удаление агента (не отвязку) и `runManager.ts`.

## Открытые вопросы / что осталось

- Судьба второго редактора политики в `apps/agent-tray` не тронута этой
  задачей — если появится желание унифицировать web и трей, там отдельная
  реализация.
