# console-history-stop

## Что сделано

- Задача «Консоль машины: история команд, повтор и отмена выполнения» уже
  реализована и закоммичена (0353f90) вместе с добавлением раздела в
  `docs/kb/machines.md`. Этот проход — kb_update: сверил содержание раздела с
  рабочей копией и дифом, закрыл 2 пробела базы, обновил свежесть тем.

## Что выяснили (факты, которых не было в KB)

- `MachineConsole` умеет: историю ↑/↓ по машине через `ConsoleHistoryStore`
  (стор, `AppState.consoleHistory`/`pushConsoleCommand`, переживает
  переоткрытие утилиты), кнопку «Стоп» на `AbortSignal`, клик по строке
  `$ команда` подставляет её в поле ввода, копирование сеанса из шапки
  `ToolFrame`. Esc в modal идёт через новый проп `ToolFrame.onEscape` — общий
  стек окон (`useDialogStack`) иначе не даёт событию дойти до input.
- REST-ручка `POST /api/agents/:id/exec` теперь пробрасывает отмену:
  `AbortController`, привязанный к `close` **ответа** (`reply.raw`, не
  `req.raw` — та же грабля, что в `mcp/remoteBashMcp.ts`), передаёт `signal` в
  `registry.exec`, который шлёт агенту `exec.cancel`.
- Живого построчного вывода консоль по-прежнему не получает: `execStream` из
  `AgentRegistry` есть и используется CI-исполнителем, но ipc-канала chunk'ов в
  браузер для консоли нет — отдельная задача при необходимости.

## Куда занесено

## Открытые вопросы / что осталось

  зафиксировано в machines.md как явный пробел, не как невыполненный пункт.
