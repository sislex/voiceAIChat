# latest-task-run-result-kb

## Что сделано

- Уточнено устройство серверного `latestRunResult`, realtime-обновления доски и доступной подсветки последней ошибки на карточке.

## Что выяснили (факты, которых не было в KB)

- Общий признак последней ошибки не зависит от legacy-пульса development CI; отсутствие результата и отмена не считаются ошибкой.
- Кнопка предупреждения открывает ленту по нормализованному `kind`, а рамка через `box-shadow` не меняет геометрию карточки.

## Куда занесено
