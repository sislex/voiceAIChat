# Студия картинок как отдельное приложение

## Что сделано

- Выделены `apps/image-studio`, порты `ImageStudioCore`/`ImageStudioService`, standalone-сервер на 8796 и адаптеры `apps/server/src/imageStudioBridge`.
- Compose запускает отдельный `image-studio`; ядро и Caddy направляют туда прежние API и `/g/*`. Формат и каталог галерей сохранены, UI остаётся общим.
- Общий гейт выявил старую зависимость `server.test.ts` от пользовательского `~/.voicechat-server`: исправлена изоляция двух тестовых серверов во временных каталогах.
- Генерация и отмена пересекают HTTP-границу; LLM и настройки пользователя остаются у ядра. Запрос отменяется и при остановке студии. Исправлено зависание промиса при асинхронном отказе/позднем подключении LLM.
- Добавлены тесты границ, контракта, отказа авторизации без ядра и интеграция embedded/remote с разными каталогами данных. Адресный прогон: 35 тестов пакета студии, 19 тестов адаптеров/интеграции ядра, 9 проверок shared — зелёные. Compose-конфигурация валидна с тестовым `VC_PUBLIC_HOST`; сборки студии и web прошли.

- Итоговый `npm run gate:fast` прошёл с кодом 0: полный fallback выполнил typecheck и все тесты монорепозитория (7501 успешных Vitest-тестов, плюс корневые проверки скриптов). Сборки студии/web и `git diff --check` также прошли.

## Что выяснили (факты, которых не было в KB)

- Прокси Make по умолчанию допускает 16 МБ и ждёт 60 секунд: для студии нужны 20 МБ JSON (12 МБ картинки в base64) и отдельный бюджет генерации. Внутренний запрос учитывает до четырёх референсов.
- При остановке Fastify ответ активного запроса может закрыться до доставки 410; прокси тогда возвращает 503. Сам LLM отменяется, а сохранённые файлы доступны после старта. Кнопка отмены без остановки сервиса возвращает 410.
- Запрос, ожидающий проверки владельца, не должен начинать генерацию после `preClose`; остановка закрывает приём новых ранов ещё до завершения HTTP-проверки.
- Слоты генерации и лимитер пароля остаются в памяти одного процесса; горизонтальное масштабирование на один каталог не добавлялось.
