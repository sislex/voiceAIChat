# kb-scopes

## Что сделано

- Базу знаний разделили на три раздела по видимости: «Использование» (файлы
  `docs/kb`, общие для всех), «Настройки пользователя» (строки `kb_documents` с
  `owner_id`) и «Разработка проекта» (`project_id`, только участники проекта).
- Контроль доступа собран в одном месте: `ScopedKnowledgeBase` (`kb/scoped.ts`)
  поверх файлового источника + «вид» пользователя `KbView` (`kb/access.ts`).
  Маршруты `/api/kb/*` отдают 403 на чужой `projectId` и 404 на чужую статью по id.
- Новый проект в той же транзакции, что и колонки доски, получает обзорную
  статью-заготовку раздела «Разработка».
- Операция «Исследовать проект» (`kb/research.ts` + кнопка в UI БЗ): модель на
  машине проекта читает репозиторий через remote-bash MCP и возвращает статьи,
  запись в базу делает сервер.
- UI БЗ: три вкладки-раздела, выбор проекта, запуск исследования с опросом
  состояния, редактор своих статей.

## Что выяснили (факты, которых не было в KB)

- Индекс должен быть один на оба источника: BM25-оценки из разных индексов
  несравнимы, поэтому статьи из БД разбираются тем же кодом, что и файлы
  (`kb/engine.ts` вынесен из `service.ts` ровно ради этого).
- `df` и средняя длина считаются только по видимым разделам: иначе оценки
  зависели бы от чужих статей и косвенно выдавали их существование.
- Токенайзер БЗ включает точку в токен (`[\p{L}\p{N}_./:-]+`), поэтому «vault.»
  в конце предложения не находится по запросу «vault» — важно для тестов поиска.

## Куда занесено

- docs/kb/features/project-knowledge-base.md (разделы, доступ, исследование)
- docs/kb/data-auth.md (таблица `kb_documents`)
- docs/kb/usage/chatai-basics.md (новая статья раздела «Использование»)

## Открытые вопросы / что осталось

- Файловые темы `docs/kb/*.md` пока целиком относятся к «Использованию», хотя по
  содержанию это разработка самого ChatAI. Разделять их имеет смысл вместе с
  переносом ChatAI в обычный проект приложения.
- Прогон исследования живёт в памяти процесса: после рестарта сервера состояние
  теряется (сами статьи, разумеется, остаются в БД).
