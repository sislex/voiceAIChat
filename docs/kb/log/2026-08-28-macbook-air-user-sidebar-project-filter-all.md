# sidebar-project-filter-all

## Что сделано

- Дополнено описание общего Sidebar семантикой и persistence проектного фильтра чатов.

## Что выяснили (факты, которых не было в KB)

- Фильтр трёхзначный: `undefined` показывает все чаты, `null` — чаты без проекта, строка — чаты конкретного проекта.
- Отсутствие ключа preferences означает «Все», `__none__` означает «Без проекта»; список и поиск по названиям фильтруются после полного ответа, а reader-списки — до фильтрации.
