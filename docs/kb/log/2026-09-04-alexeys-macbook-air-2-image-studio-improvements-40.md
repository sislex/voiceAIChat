# image-studio-improvements-40

## Что сделано

- Итерация 40: пометки следуют за файлом при переименовании и переносе и
  чистятся при удалении навсегда; перенос пометок текстом между браузерами;
  команды галереи в палитре ⌘K; шпаргалка клавиш галереи; Shift+клик —
  диапазон; вес выбранного в сводке; пакетная правка моделью; прерывание
  пакетной операции; проверка квоты перед пакетом; «Ссылка на файл».
- Попутно: диалоги студии получили проп `padded` (включая давний диалог
  пароля) — без него содержимое прижималось к краям окна.

## Что выяснили (факты, которых не было в KB)

- `Dialog` из ui-kit по умолчанию не даёт внутренних отступов: содержимое
  рендерится прямым ребёнком `.vc-dialog`. Отступы включает проп `padded`
  (обёртка `.vc-dialog-body`).
- Клавиша «?» уже занята общей шпаргалкой приложения. Свой обработчик в
  панели открывал два окна одновременно — экранным клавишам нужен реестр
  команд, а не второй слушатель.
- В Chrome на macOS ⌘K перехватывает браузер (поиск в адресной строке), и до
  страницы событие не доходит. Для проверки палитры в автоматизации помогает
  синтетический `KeyboardEvent('keydown', { key: 'k', metaKey: true })` на
  `window`.
- Мгновенный фейк моста делает тест прерывания пакета бессмысленным: пачка
  успевает пройти целиком до нажатия кнопки. Первый вызов надо «подвесить»
  через `mockImplementationOnce` с отложенным `resolve`.

  и прерывание — dom-тестом с подвешенным первым вызовом.
- Цикл продолжается: итерация 41 по /loop.
