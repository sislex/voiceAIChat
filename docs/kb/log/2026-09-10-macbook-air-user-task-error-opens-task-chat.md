# task-error-opens-task-chat

## Что сделано

- Дополнена тема интерфейса поведением перехода с ошибки последнего этапа во встроенный чат задачи.

## Что выяснили (факты, которых не было в KB)

- Новая и legacy-карточки открываются на вкладке AI-чата с редактируемым локальным диагностическим черновиком; сообщение не отправляется автоматически, а разговор остаётся task-scoped через `tasks:openChat`.
