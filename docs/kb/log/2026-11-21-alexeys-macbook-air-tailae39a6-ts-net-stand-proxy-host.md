# stand-proxy-host

## Что сделано

- Локальный стенд по адресу (`us-<машина>-<порт>`) теперь получает исходный Host адреса стенда (`localhost:<порт>`): Make передаёт `host` в `userStand {op:'preview'}`, прокси отправляет его и Origin корню аренды и переписывает абсолютные перенаправления на этот адрес в адрес аренды.

## Что выяснили (факты, которых не было в KB)

- Раньше прокси всегда подставлял `Host: 127.0.0.1:<порт>`. Минимальная сборка sislexa.by различает сайты по Host (Caddy): `localhost` — чат, `127.0.0.1` — хранилище. Через стенд открывался интерфейс хранилища, он перенаправлял на `http://localhost:29080/applications/storage/open` мимо прокси, вход шёл в чужом для рамки адресе, и cookie не сохранялись.
