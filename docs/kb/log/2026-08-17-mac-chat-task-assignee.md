# chat-task-assignee

## Что сделано

- Дополнена тема проектов описанием выбора исполнителя в черновике задачи из чат-предложения.

## Что выяснили (факты, которых не было в KB)

- Перед открытием черновика UI получает `ProjectDetail` проекта чата и сохраняет его участников вместе с предложением.
- Новый черновик не назначен по умолчанию; UI исключает заблокированных участников, а сервер проверяет активное членство при создании и обновлении.
- Ошибка создания оставляет форму и все её поля открытыми для повторной попытки.

- `docs/kb/projects.md`, раздел «Создание задачи по запросу ассистента».
