# merge-runner-cross-machine-cleanup

## Что сделано

- Зафиксировано поведение merge-рана на выбранной машине без готового клона: постоянный project-scoped клон создаётся из Git URL в настроенном `repos_root`.
- Зафиксирована очистка task-specific каталогов после успешного merge и подтверждённого push, включая восстановление незавершённого рана через reconcile.
- Добавленные тесты покрывают отсутствие `repos_root`, недоступную машину, запрет очистки при падении проверок и очистку после подтверждения ранее начатого push.

## Что выяснили (факты, которых не было в KB)

- При reconcile совпадение `origin/main` с сохранённым merge SHA теперь не только завершает ран успехом, но и запускает обычный `releaseTaskRepositories`.
- Репозитории на недоступных машинах не удаляются и остаются active до следующей попытки очистки; при ошибке до подтверждённого push очистка не запускается.
