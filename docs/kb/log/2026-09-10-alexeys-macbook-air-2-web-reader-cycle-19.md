# web-reader-cycle-19

## Что сделано

Полный Chromium выбирается внутри Web Reader без нового разговора. Выбор
сохраняется в БД; модель, пользовательский ввод, кадры и логическая навигация
используют одну сессию. Десять связанных улучшений перечислены в плане.

## Что выяснили

Страница с frame-ancestors none требует настоящего браузера. Уже существующий
раннер можно подключить к web-recorder через общий признак выбранного движка.
Поллинг кадров не должен перезаписывать автора действий или черновик адреса.
Literal loopback доверенного preview origin раньше отсекался до проверки
настроенного оператором разрешения. Метаданные модели должны разворачивать
технический URL прокси обратно в app.internal.
