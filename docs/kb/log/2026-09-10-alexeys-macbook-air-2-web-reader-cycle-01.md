# web-reader-cycle-01

## Что сделано

Первый цикл из двадцати: десять исправлений HTML-прокси Reader. Список и время —
[журнал задачи](../../plans/web-reader-20-cycles.md). URL-атрибуты теперь разбирает
HTML-парсер; добавлены десять unit и десять Chromium-регрессий.

## Что выяснили

Regex-rewrite затрагивал строки JavaScript и data-атрибуты, не учитывал базу
документа и unquoted attributes. Inline modules обходили маршрут прокси, а SRI
мешал загрузке изменённых ресурсов. Эти случаи воспроизведены тестами.

## Куда занесено

- docs/kb/server-internals.md — раздел «Прокси веб-превью».
- docs/kb/ui.md — актуальные ожидания QA таблицы тарифов (сопутствующий ремонт гейта).

## Проверки

- Unit: 10/10; Chromium: 10/10 (01:33 +03:00).
- Первый запуск Chromium выявил неверный charset тестовой страницы; фикстура
  получила явный UTF-8, после чего весь набор прошёл.
- `gate:fast`: код 0 после ремонта устаревшего теста; `gate`: код 0, 01:50 +03:00.
- Реальный Web Reader загрузил страницу входа собственного приложения с deep link;
  временный сервер/БД очищены, снимок просмотрен.
