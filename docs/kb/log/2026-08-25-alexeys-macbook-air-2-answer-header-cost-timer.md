# answer-header-cost-timer

## Что сделано

- Редизайн шапки/подвала ответа ассистента (ChatColumn):
  - Шапка `.msg-head`: движок → селект «Вид ответа» (список TIMELINE_MODES вместо
    циклической кнопки, переключается во время ответа) → справа время начала ответа
    (clockTime(createdAt−durationMs), тултип) + иконка «Копировать ответ».
  - Модель скрыта по умолчанию, показывается при наведении на движок (CSS + title).
  - Подвал: время конца (тултип), токены, ориентировочная стоимость, «Подробнее».
  - Стоимость: реальная meta.costUsd из ответа модели как есть, иначе расчётная по
    прайс-таблице (estimateCostUsd) с пометкой «≈».
  - Живой ход: таймер «Отвечает: мм:сс», обновляется раз в секунду.
- Чистые хелпера в lib/view.ts: clockTime, dateTimeTooltip, formatElapsed, messageCost.
- Гейты: shared 557, ui 1787, storybook build, web build, typecheck всего.

## Что выяснили (факты, которых не было в KB)

- estimateCostUsd (packages/shared/src/pricing.ts) уже даёт расчёт по токенам —
  переиспользован для стоимости в чате (реальную цену не подменяет).
- liveMode был const useState без сеттера — сделан переключаемым.

## Куда занесено

- docs/kb/ui.md — абзац «Шапка и подвал ответа ассистента».

## Открытые вопросы / что осталось

- Точный момент старта живого ответа фиксируется на клиенте (появление стрима),
  а не по серверному времени первого токена — для отображения таймера этого достаточно.
