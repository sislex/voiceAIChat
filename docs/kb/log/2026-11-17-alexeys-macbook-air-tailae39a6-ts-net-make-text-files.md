# make-text-files

## Что сделано

- На стенде с API моделей беседа Make получает файлы проекта в запросе, а блоки `<make-file>` из ответа Core сам записывает в проект через инструменты Make.

## Что выяснили (факты, которых не было в KB)

- Решение владельца 2026-11-17: на стенде без инструментов моделей Make работает «файлами через текст», без обратного канала.
- Адрес инструментов Make принимает одиночный JSON-RPC `tools/call` без инициализации сессии.

## Открытые вопросы / что осталось
