# make-project-3-empty-shell

## Что сделано

- Сверены с `main` новые состояния общего shell для пустых чатов и проектов.
- Дополнена существующая тема UI и перегенерирован индекс базы знаний.

## Что выяснили (факты, которых не было в KB)

- Пустая страница чатов появляется только при `ready`, отсутствии активной беседы и полном отсутствии бесед; её действие открывает существующее создание разговора.
- `#/projects` без проектов показывает отдельную страницу с действием существующего `NewProjectDialog`; общий toggle сохраняет desktop collapse и mobile drawer.
