# Канбан-ассистент по макету «Проект 14»: вторая итерация CHAT-391

## Что сделано

- `KanbanAssistant` переписан под разметку макета: боковая колонка чатов (поиск, новый чат, статусы, удаление, легенда), шапка со знаком и статус-пилюлей, приветственный экран с подсказками, композер, прижимающийся к низу после первого сообщения, лента с пузырями и стримом; предложения и планы — карточки в ленте; настройки LLM — по кнопке в шапке; автопилот — тумблер в композере.
- `WidgetAssistantFrame.hideHeader`; App отдаёт ассистенту `onSelectConversation`/`onClose`, селектор из шапки рамки убран.
- CSS `.ka-*` с токенами макета, container queries по панели (выдвижная колонка чатов до 900 px).
- Тесты `WidgetAssistantFrame.dom.test.tsx` переписаны под новую разметку и дополнены; сториз пустого диалога, ошибки и недоступного транспорта.

## Что выяснили (факты, которых не было в KB)

- Первая реализация CHAT-391 (`6446be61`) дала только палитру и строку статуса поверх `ChatColumn`/`VoiceBar`, поэтому после деплоя 0.1.219 пользователь «не видел новый шаблон» — критерий «панель соответствует опубликованному шаблону» фактически не выполнялся.
- Файлы Make-проекта на проде читаются через `GET /api/make/:conversationId/file?path=…` (в браузере под сессией), а превью — `GET /api/preview/make/:conversationId/index.html`; макет «Проект 14» — статичный `index.html` + `styles.css` + демо-`app.js`.
- Инструмент чтения страницы Chrome режет вывод ~1000 символов и блокирует base64 — длинные файлы удобнее читать через превью-скриншоты и короткие срезы `slice`.
