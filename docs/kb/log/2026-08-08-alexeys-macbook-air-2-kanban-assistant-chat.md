# kanban-assistant-chat

## Что сделано

- Сверён и зафиксирован сохраняемый приватный чат канбан-ассистента и наследование его LLM-конфигурации.
- В карту свежести проектной темы добавлены исходники UI, IPC и общего контракта ассистента.

## Что выяснили (факты, которых не было в KB)

- Ход выбирает `llmEngineId` в порядке чат → проект → пользователь, а `provider/model` служебного чата по умолчанию заново получает из проекта.
- Без собственного project config проект и его канбан-чат используют пользовательские LLM-дефолты; собственные значения разговора имеют приоритет и сбрасываются в `NULL`.
