# context-usage-last-call

## Что сделано

- Заполнение контекста беседы для Claude считается по входу последнего вызова модели в ходе (`TurnMeta.contextInputTokens`), а не по сумме всех вызовов. `createClaudeSink` запоминает usage последнего сообщения ассистента, `conversationContextUsage` использует его.

## Что выяснили (факты, которых не было в KB)

- Итоговая строка `result` Claude CLI несёт сумму usage по всем вызовам модели в ходе. Индикатор под полем ввода после хода с инструментами показывал сумму: на проде в Make «197 453 / 128 000» красным, в Workspace после хода из 4 вызовов — 113 147 при реальных ~39 тыс.

## Куда занесено

- docs/kb/server-internals.md

## Открытые вопросы / что осталось

- Окно модели для псевдонимов (`haiku`, `sonnet`) берётся по умолчанию 128 000 — не менялось.
- Вызовы подагентов (Task) тоже дают сообщения ассистента; последним может оказаться вызов подагента.
