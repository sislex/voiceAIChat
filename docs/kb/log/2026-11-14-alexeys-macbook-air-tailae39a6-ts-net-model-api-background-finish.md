# model-api-background-finish

## Что сделано

- Запуск API моделей после отключения вызывающей стороны (или DELETE) не гасится, а доигрывает в фоне и закрывается по фактическому расходу.
- Лимит одновременных запусков на токен по умолчанию 4 (было 2).
- Закреплены пакеты Make 1.8.21 (поезд закрепляет только образ make-api; интерфейс make-ui берётся из пакета `@sislexa/make`).

## Что выяснили (факты, которых не было в KB)

- Раннер при отключении клиента убивает CLI; квитанция получается `finished` без итогового расхода, резерв в Billing становится `uncertain`, запись учёта остаётся `dispatching` и навсегда занимает слот токена (`concurrency_limit_exceeded`).
- Один токен обслуживает весь стенд: ход чата, заголовки и сводки идут одновременно.
