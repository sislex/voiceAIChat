# parallel-worktree

## Что сделано

- Заведён второй чекаут монорепо для параллельной работы: `git worktree add ../voiceAIChat1 -b work1`
  (общий `.git`, отдельное рабочее дерево), свой `npm install`, свой `.env`.
- Разведены порты и данные второго сеанса: `PORT`/`VC_API_PORT` 8797, `VC_WEB_PORT` 5283,
  `VC_RECORDER_PORT` 5284, `VC_DATA_DIR=~/.voicechat-server1` (копия БД; `models` внутри —
  симлинк на основной каталог, чтобы 465 MB моделей не дублировались).
- `scripts/dev-web.sh` и `apps/web-recorder/vite.config.ts` научены читать порты из окружения
  (значения по умолчанию прежние — 8787/5273/5274).

## Что выяснили (факты, которых не было в KB)

- Порты были параметризованы только в `apps/web/vite.config.ts`. `dev-web.sh` хардкодил их
  в сообщениях и в `wait_port`, а recorder — свой `5274` и прокси на `8787`. Из-за этого
  `npm run dev:web` на других портах не поднимался: backend вставал на новый порт, скрипт
  ждал готовности старого и падал по таймауту 30 с.
- `VC_DATA_DIR` по умолчанию — `~/.voicechat-server`, общий для всех чекаутов на машине.
  Без развода два dev-сервера пишут в одну SQLite.
- Скрытый дефект в `dev-web.sh`: `[ -f "$X" ] && export ...` под `set -e` возвращает 1 и роняет
  скрипт, когда артефакта нет. В основном чекауте whisper-cli и `.venv-piper` на месте, поэтому
  дефект не проявлялся; во втором чекауте (без `apps/desktop/node_modules`) сломал бы запуск.
  Починено добавлением `|| true`.
- `VC_WHISPER_CLI`/`VC_MODELS_DIR`/`VC_PIPER_BIN`/`VC_PIPER_VOICES_DIR` из `.env` переживают
  запуск: `dev-web.sh` перебивает их только когда находит файлы локально. Поэтому второй чекаут
  переиспользует тяжёлые артефакты первого без копирования.

## Куда занесено

- `docs/kb/testing-operations.md` — абзац про dev-порты дополнен; добавлен абзац
  «Второй чекаут монорепо рядом с первым».

## Открытые вопросы / что осталось

- Правки лежат в ветке `work1` некоммиченными: в `main` они не попадут, пока их не смёржить.
  Основному чекауту они не нужны (он на портах по умолчанию), но при мерже `work1` уедут вместе
  с задачей — стоит вынести отдельным коммитом.
