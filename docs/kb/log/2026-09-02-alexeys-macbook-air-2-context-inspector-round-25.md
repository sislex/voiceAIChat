# Круг 25: хинты исполнителя и движок-исполнитель

Третий круг аудита «что модель получает, а инспектор не показывает».

- **Системные хинты раннера** (машина, БЗ, превью, Make, консоль, канбан)
  перечислены в `omitted` с размерами для текстов из shared. Попутная находка:
  один только хинт браузера превью — ≈661 токен в каждом ходе обычного чата.
- **Движок-исполнитель**: `resolveLlmEngine` с ролевым откатом теперь виден в
  details пункта `llm`, замена закреплённого движка даёт предупреждение.

Оба изменения проверены падением тестов без починки и живым стендом.

## Чего стоило избегать

**Iframe-стенд в браузерной вкладке смывается навигацией SPA.** Инжектированный
в body iframe пережил проверку омитов, но пропал, когда вкладка перешла на
другой маршрут. Для карточки пункта надёжнее вести саму вкладку по адресу
(`#/chat/:id/context/llm`), а не держать стенд внутри чужой страницы.
