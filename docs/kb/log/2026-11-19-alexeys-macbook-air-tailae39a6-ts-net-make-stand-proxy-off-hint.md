# make-stand-proxy-off-hint

## Что сделано

- Подсказка режима `make-preview` в промпте хода Make объясняет код `make_stand_proxy_off` (стенд с выключенным серверным прокси) и предлагает включить прокси через `stand_update`.

## Что выяснили (факты, которых не было в KB)

- «Ассистент не видит стенд» в беседе `cf2fda81` на стенде 25273 после включения транзита: у подключённого стенда был выключен прокси (`boundProxy: false`), рамка шла по прямому адресу и не отвечала на действия; хост отдавал `make_preview_closed`. Make #187 отвечает теперь `make_stand_proxy_off`.
- Вопрос без ответа после перезапуска Core посреди хода — особенность стендового `run.sh` (процесс `tsx watch` убивается без ожидания): при плановой остановке (`SIGTERM` → `app.close()`) `flushInterrupted` сохраняет прерванный ответ.
