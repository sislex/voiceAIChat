# tts-runner

## Что сделано

- Зафиксирован вынос синтеза речи из server в отдельный `@voicechat/tts-runner`.
- Обновлены обзор речевого пути, серверные внутренности и корневые указатели KB.

## Что выяснили (факты, которых не было в KB)

- TTS использует Bearer-защищённый ресурсный API: JSON lifecycle отдельно от WAV.
- Runner единолично управляет Piper/say, очередью, отменой, таймаутами, временными файлами и физическим каталогом голосов.
- Сервер работает только через `TtsClient`; отказ TTS не блокирует STT или текстовый чат.
