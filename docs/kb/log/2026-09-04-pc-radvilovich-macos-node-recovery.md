# Самовосстановление Node.js на macOS

## Что сделано

Обновлена тема о компаньон-агенте: зафиксированы выбор macOS-релиза Node.js,
проверка системного, сохранённого и скачанного бинарника, безопасная замена
portable-каталога и остановка установки до npm при ошибке.

## Что выяснили (факты, которых не было в KB)

macOS выбирает первый актуальный релиз линии v22 после полного чтения
`index.json`; Linux по-прежнему берёт первую запись. Node принимается только при
успешном `node --version`, строгом `vX.Y.Z` и major 22+.

Повреждённый `$AGENT_DIR/node` удаляется только после проверки кандидата в
`node.tmp`. Ошибка восстановления на macOS сообщает версию ОС, архитектуру,
выбранный релиз и причину и не допускает перехода к npm.
