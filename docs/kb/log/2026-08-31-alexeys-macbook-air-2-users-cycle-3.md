# Круг 3 улучшений страницы «Пользователи»

## Что сделано

- **Журнал фильтрует сервер**: `GET /api/admin/security?group=auth|account|machines`.
  Разбиение по группам переехало в `packages/shared/src/admin.ts` — по нему
  фильтруют и сервер, и подписи UI, а две копии разошлись бы на первом же новом
  типе события.
- **Сводка расхода умеет `users=`** (сузить до видимых), **отчёт не запрашивается
  у человека без единого разговора**, **отказ сводки не оставляет администратора
  без списка людей**.
- **Расход в строке списка** и **видимый выбор порядка** (по активности / имени /
  расходу): сортировка по расходу раньше существовала только в адресе.
- **Экспорт списка людей в CSV** — ровно текущая выборка, а не «все».
- **`ProgressBar` в ui-kit** вместо самодельных полос; **`Avatar` принимает фото**;
  сравнение расхода с прошлым периодом (только когда прошлый ненулевой).
- Мобильная карточка: действия человека встают в строку под именем; метрика
  «активны сейчас» объясняет ноль.
- Сториз: расход с данными, много машин, длинные имена, ошибка вкладки.

## Что выяснили (факты, которых не было в KB)

- **`packages/profile-app` не может импортировать `@voicechat/shared`** — его
  архитектурный гвард разрешает только `react` и `@voicechat/ui-kit`. Поэтому
  доменные правила (группы событий) живут в контракте и применяются **на сервере**,
  а модуль профиля получает уже отфильтрованные данные и только рисует их.
  Это лучше дубля: копия разбиения в UI неизбежно разошлась бы с серверной.
- **Нулевой расход в строке списка вреден**: «$0.00» у всех создаёт видимость
  данных там, где их нет. Пустое место честнее.
- **Отчёт расхода для человека без разговоров — гарантированно пустой ответ**:
  `conversationCount` в списке позволяет не ходить за ним вовсе.

## Открытые вопросы / что осталось

- ETag на `GET /api/admin/users` (пункт 5 круга) не сделан: нужен способ дёшево
  считать версию списка, иначе хеширование ответа съест выигрыш.
- Серверная фильтрация самого списка людей по-прежнему не нужна на текущих
  объёмах, но станет нужна на тысячах учёток.
