# 108-live-run-timers

## Что сделано

- В ленте CI-рана добавлен секундный тик для живых длительностей без новых логов.
- После успешного cleanup связанный чат возвращается из удалённого клона в папку машины проекта; стартовая миграция исправляет только пути released workspace.
- Исход встроенной актуализации БЗ включён в резюме связанного чата, а промпт проверки направляет модель в штатный гейт.

## Что выяснили (факты, которых не было в KB)

- Пока ран не терминален, `RunFeed` перерисовывается раз в секунду и вычисляет текущие длительности через проп `now`; после завершения показывает сохранённые `durationMs`.
- Успешный cleanup освобождает workspace и восстанавливает `exec_target`/workdir чата по default agent и пути проекта; старые чаты миграция меняет лишь внутри released workspace.
