# Web Reader: название и маршрутизация

## Что сделано

- Актуализирована тема UI после переименования отдельной страницы веб-превью в Web Reader.
- Зафиксированы канонический и совместимый legacy-маршруты, а также правила выбора разговора.

## Что выяснили (факты, которых не было в KB)

- Канонический адрес — `#/web-reader/:id`; `#/web-recorder/:id` заменяется без новой записи истории.
- Web Reader принимает только разговоры типа `web-recorder` и миграционные разговоры с `previewUrl`.
- ID обычного чата заменяется первым Reader-разговором; новый создаётся только если подходящих разговоров нет.
