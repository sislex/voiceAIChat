# tool-transit-token-grant

## Что сделано

- Транзит инструментов API моделей закрыт отдельным правом токена: таблица `model_token_grants` в Core, выдача администратором через `PUT /api/admin/model-tokens/:sid/tool-transit`.
- Без права сокет транзита закрывается, возможность `toolTransit` не объявляется, ход с `transit` получает 403 `tool_transit_denied`; приложение остаётся в текстовом режиме.
- Стенд с API моделей забывает сессию Claude прежнего поставщика («No conversation found») и повторяет ход в новом треде — как уже делалось для Codex.

## Что выяснили (факты, которых не было в KB)

- Токены API моделей — сессии Identity с классом доступа `full` / `read` / `models`; отдельных прав у них нет, и новое значение класса потребовало бы выпуска Identity. Поэтому право хранится в Core по `sid` токена.
- Существующие токены права не получают; выданное позже право начинает действовать при следующем переподключении приложения (15 с).

## Открытые вопросы / что осталось

- В интерфейсе создания токенов выбора права нет: оно выдаётся отдельным запросом администратора после создания токена.
