# chat-machine-access

## Что сделано

- Сверена и актуализирована модель доступных машин в настройках обычного и проектного чата.
- Расширены `areas` темы на серверный гейт, общий контракт и UI настроек.

## Что выяснили (факты, которых не было в KB)

- Сервер объединяет личные и проектные машины только для действующего участника проекта и удаляет дубли.
- Один `canUseAgent` защищает сохранение `execTarget`; UI сбрасывает ставшую недоступной цель, папку и навыки.
