# Playwright Reader — цикл 07, ожидание готовности

Десять пунктов: текст внутри selector, state, enabled, editable, checked, value,
count, публичный URL, loadState и predicate. Все условия делят общий дедлайн,
успех сообщает waitedMs. count включает скрытые узлы и ноль; для видимости можно
задать state явно. Predicate синхронный, его Promise не выдаётся за true; код
проходит ту же проектную политику, что evaluate, без подтверждения изменений.

На исходной реализации упали 11 живых регрессий. После интеграции — 35/35
адресных runner-тестов; окончательный набор ожиданий 11/11 за 5,58 с. Shared до
добавления проверки mapper — 50; MCP после проверки политики — 61. Полный
монорепозиторный typecheck прошёл, web собран за 48,71 с.

Первый E2E дошёл до новых условий, затем служебный evaluate изменения DOM
отклонила политика. Стенд получил обычную кнопку очистки, E2E нажимает её через
click. Повторный E2E — 10/10 за 14,52 с. Изменение политики не потребовалось.

Общая интеграция — 593 с; черновики готовились отдельно во время гейтов 06,
пересекающийся интервал записан в JSON. Гипотеза медленного закрытия тестового
HTTP-сервера не подтвердилась и не исправлялась. Знания: features/playwright-reader.md.
Учёт пунктов и времени: docs/plans/playwright-reader-20-cycles.json. Финальная проверка цикла 07: gate:fast exit 0, 7349 passed / 45 skipped, 466,94 с; полный gate exit 0, 7680 тестов, web и Storybook, 539,33 с. E2E 10/10 за 14,52 с.
