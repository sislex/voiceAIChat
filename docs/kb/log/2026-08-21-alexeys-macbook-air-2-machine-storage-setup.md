# machine-storage-setup

## Что сделано

- Актуализировано описание настройки постоянного хранилища подключённой машины.

## Что выяснили (факты, которых не было в KB)

- Регистрация выполняется только после проверки каталога и marker; существующий корректный marker подключается с прежним id.
- Статус хранилища отражает доступность каталога и согласованность marker, а не только online-состояние агента.
- Интерфейс предлагает платформенный путь из домашнего каталога, допускает существующую директорию, повторную проверку и отложенную настройку.
