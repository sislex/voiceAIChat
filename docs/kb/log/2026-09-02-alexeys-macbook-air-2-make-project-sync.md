# Make ↔ репозиторий проекта: компоненты и стили туда и обратно

Новая функция по запросу пользователя: в Make-чате, привязанном к проекту,
можно скопировать компоненты и стили из рабочей директории машины проекта в
мастерскую, поправить их там (ассистент, превью) и вернуть обратно.

Устройство: серверные роуты project-files/links/pull/push в `routes/make.ts`,
файловый мост машины — `agentRegistry.fsList/fsRead/fsWrite` (политику записи
проверяет агент), связи в `.project-links.json` с sha256 на момент копирования,
диалог `MakeProjectSyncDialog` в меню «Ещё» панели Make.

Ключевые решения:
- **push пишет только связанные файлы** — мастерская не может тронуть в
  репозитории ничего, что сама не забирала;
- **конфликт — это 409, а не молчаливая перезапись**: force шлёт только
  подтверждение пользователя в UI;
- пути только относительные без `..`; скрытое и node_modules в листинге
  спрятаны; лимит 40 файлов за копирование.

Проверено: 6 серверных тестов (фейковый мост) + красная проверка конфликтной
защиты; 3 dom-теста диалога; живой стенд с настоящим агентом
(`apps/agent` → `--root <репо>`): pull, статусы, 409, force, файл в
репозитории заменён, подтверждение в браузере.

## Попутный факт

Локальный агент поднимается одной командой:
`VC_AGENT_SERVER=ws://127.0.0.1:8799/agent VC_AGENT_TOKEN=<токен из POST /api/agents> npx tsx src/index.ts --root <каталог>`
из `apps/agent` — удобно для живых проверок машинных функций на стенде.
