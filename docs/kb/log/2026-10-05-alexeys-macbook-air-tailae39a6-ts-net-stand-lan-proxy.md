# stand-lan-proxy

## Что сделано

- Доступ к стенду из локальной сети идёт через отдельный прокси `stand-lan` (Caddy), ядро стенда
  публикуется на `127.0.0.1:<порт стенда>`.

## Что выяснили (факты, которых не было в KB)

- U04: на M1 (Docker Desktop, Docker 29.8.1) контейнер с двумя публикациями одного порта контейнера на
  разные не-loopback адреса (LAN 192.168.1.9 и VPN 100.126.46.22) не создаётся: Docker Desktop переводит
  обе в `127.0.0.1` со случайным портом и падает с `address already in use`. С разными портами
  контейнера всё работает (проверено одноразовым контейнером). Повторы шага `start` это не лечат.
