# model-api-text-only-with-transit

## Что сделано

- Стенд с API моделей и `VC_CHAT_TEXT_ONLY=true` остаётся без инструментов, даже если поставщик объявил транзит: Make продолжает работать текстовым протоколом файлов.

## Что выяснили (факты, которых не было в KB)

- После включения транзита на проде стенд 25273 в текстовом режиме потерял Make целиком: транзит отключал текстовый протокол файлов, а текстовый режим отключал инструменты. Оба хода (Haiku и gpt-5.6-luna) в новом проекте отвечали «инструменты Make недоступны» и ничего не записывали; запрос был 4 938 токенов — без файлов проекта.
