# Playwright Reader — цикл 05, точность снимков модели

Десять пунктов: rect, fullPage, контекст страницы, настоящая область элемента,
смещение viewport, CSS-масштаб модели, PNG quality, конфликт режимов, анимации,
ограничение ожидания снимка и шрифтов. Метаданные передаются рядом с бинарём;
при их отсутствии приложение не подставляет размеры из прежнего start.

Исходно упали 10 Chromium-проверок и 6 MCP-проверок. После исправлений прошли
26 адресных runner-тестов, 22 приложения и 12 remote HTTP. MCP после добавления
параметров прошёл 45 тестов; дополнительный отказ fullPage для iframe проверяет гейт.
Полный E2E прошёл 8/8 за 38,80 с; PNG области 160×90 и всей страницы визуально
проверены. Первый E2E ошибочно ожидал 1800 вместо фактической высоты 1824 из-за
отступа заголовка: теперь сверяются scrollHeight, PNG и подпись снимка.

Реализация общей группы — 827 с, не суммировать по десяти пунктам. Тест шрифта
позже сделан независимым от нагрузки: ресурс завершается явно после проверяемого
таймаута, затем успешно выполняется следующий снимок. 10/10 живых проверок прошли.

Знания обновлены в features/playwright-reader.md, учёт времени и результатов —
docs/plans/playwright-reader-20-cycles.json. Оба обязательных гейта завершились успешно.

Финальная проверка цикла 05: gate:fast exit 0, 7304 passed / 45 skipped, 326,56 с; полный gate exit 0, 7635 тестов, web и Storybook, 618,44 с. E2E 8/8 за 38,80 с. Общая реализация — 827 с, уточнение теста шрифта и повторные проверки записаны отдельно в JSON.
