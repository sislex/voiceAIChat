# task-chat-highlight

## Что сделано

- Список чатов подсвечивает чаты задач так же, как канбан подсвечивает карточки:
  `.convo--ci-*` считается той же `ciCardPulse` и переиспользует кейфреймы
  `jcard-ci-*`. Мигает только активный ран; `failed`/`done` — статичная рамка.
- Принадлежность к задаче видна всегда: `.convo--task` (accent-полоска) плюс
  строка `.ctask` — иконка типа, ключ `PRJ-42`, лозенга статуса рана.
- Шапка открытого чата задачи (`TaskChatHeader`) подсвечивается тем же расчётом
  (`.taskchat--ci-*`), живую сводку получает пропсом `summary`.
- Новый источник данных: `GET /api/conversations/task-chats` →
  `db.taskChatBadges(userId)`, канал `conversations:taskChats`, стор
  `taskChatBadges` + мерж ранов в `ciSummaries`.

## Что выяснили (факты, которых не было в KB)

- Кадры `ci.*` рассылаются **всем соединениям пользователя** (`session.ts`
  подписывает сессию на `deps.ci` без привязки к подписке на доску), поэтому
  живая подсветка вне доски не требует ни новой подписки, ни нового WS-кадра —
  не хватало только начального снапшота сводок.
- `state.ciSummaries` до этого наполнялся лишь из `board:get`/`board.update`,
  то есть существовал только пока открыта доска нужного проекта.
- Медленный ответ снапшота может быть старее живых кадров: сводку из него берём
  только для незнакомого `taskId` или другого `run.id`.
