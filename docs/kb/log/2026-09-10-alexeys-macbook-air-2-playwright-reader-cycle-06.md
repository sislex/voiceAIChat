# Playwright Reader — цикл 06, чтение и поиск

Десять пунктов: структура страницы, порции текста, чтение изменённых полей,
скрытие password в describe, экранирование атрибутов, исполняемые селекторы find,
число совпадений, visibleOnly, таблицы и каталог iframe. Публичные адреса ссылок
и фреймов восстанавливаются по host aliases. Размер структуры ограничен отдельно
от текста, чтобы ответ модели оставался пригодным JSON.

На исходной реализации упали 10/10 живых проверок. Прошли 44 адресных теста
раннера; после добавления пределов данных — 12/12 проверок чтения. MCP — 48,
iframe — 33, shared — 46. Typecheck раннера и сборка web успешны. Два старых теста
чтения/поиска с заглушками заменены более полными проверками в Chromium.

Интеграция общей группы — 415 с. Черновики в /tmp готовились ещё во время
гейта 05: пересекающийся интервал записан в JSON, время не суммируется дважды.
В процессе реализации устранены остаток прежнего блока find и ошибка передачи
строки-функции в evaluate: Playwright возвращает её без вызова. Теперь функция
собирается из константы в Node и сериализуется Playwright для вызова в документе.

Знания: features/playwright-reader.md. Пункты, интервалы и результаты проверок:
docs/plans/playwright-reader-20-cycles.json. E2E и обязательные гейты выполняются.

E2E прошёл: 9/9 за 23,78 с (весь процесс 24,58 с), снимок панели визуально проверен. Первый быстрый гейт остановился на TS18048 в webReaderDiagnostics: общий total необязателен. Добавлена проверка типа; повторный быстрый гейт выполняется. Это совместимость контракта, не дополнительный пункт цикла.

Второй быстрый гейт нашёл ошибку формы нового MCP fake: в result отсутствовал ok. Форма исправлена, отдельный server typecheck exit 0; третий быстрый гейт выполняется.

В чистом Chromium проверены публичные Gmail и Instagram: структура форм входа, диалог cookies Instagram, снимки просмотрены. Чтение Gmail — 883 мс, Instagram — 1118 мс. При ревью обнаружен и воспроизведён крайний случай пустой страницы: textContent подставлял исходники script/style вместо пустого innerText. Исправлено в составе 06-01; прошли 13/13 живых проверок чтения.

Финальные гейты цикла 06: gate:fast exit 0, 7320 passed / 45 skipped, 593,34 с; полный gate exit 0, 7651 тест, web и Storybook, 533,14 с. E2E 9/9 за 23,78 с. 13 тестов чтения в полном гейте — 3,01 с.
