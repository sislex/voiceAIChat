# Make: публичный контракт и клиент

Порты MakeCore/MakeService, RPC, события и scope-токены. Реализация приложения
и файлов мастерской сюда не импортируется. Ядро в remote зависит от этого
пакета, а встроенная композиция подключает @voicechat/make отдельно.

Изменение публичной поверхности требует контрактных проверок Make и
apps/server/src/makeBridge. Команда: npm run gate:app -- make-contracts.
