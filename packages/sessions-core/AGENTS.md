# @voicechat/sessions-core

Переносимое ядро модуля «сессии и устройства»: типы, разбор устройства,
политики, порт `SessionStore` и контракт к нему. Подробности и пример
встраивания — в [README.md](README.md).

## Правила пакета

- **Ноль зависимостей и ноль платформы**: ни react, ни `node:*`, ни fetch, ни
  DOM. Пакет должен собираться в браузере, в Node и в чужом рантайме — поэтому
  хеш ключа устройства свой (FNV-1a), а не из `node:crypto`.
- Русских подписей здесь нет: тексты живут в UI-модуле `@voicechat/sessions-app`.
  Ядро отдаёт величины (`durationOf`) и структуры, а не готовые фразы.
- Время приходит из часов реализации: у методов порта нет аргументов `now`/`at`,
  иначе контракт нельзя прогнать одинаково на памяти, на SQLite и на сервисе.
- Меняешь поведение хранилища — сначала правь контракт в `src/testing/`, потом
  реализации. Контракт гоняется в этом пакете и в `apps/server`.

Гейт: `npm run -w @voicechat/sessions-core test` + `typecheck`.
