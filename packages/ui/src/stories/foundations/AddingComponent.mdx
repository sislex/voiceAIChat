# Как добавлять компонент

Короткий чек-лист перед тем, как заводить новый экран или виджет в
`packages/ui`. Полные правила — в `packages/ui/AGENTS.md` (раздел «Правила») и в
`docs/kb/ui.md`; здесь — то, что чаще всего забывают.

## 1. Сначала посмотри, нет ли готового примитива

`components/ui/` уже закрывает большую часть случаев, и свой аналог заводить не нужно:

- кнопка — `Button` / `IconButton` (варианты `primary` / `secondary` / `ghost` / `danger`, размеры `sm` / `md`);
- модальное окно — `Dialog` (портал, ловушка фокуса, Esc, полный экран на телефоне);
- уведомление — `useToast()`, подтверждение — `useConfirm()`;
- всплывающая панель инструмента — общий `ToolFrame`.

`window.confirm` / `alert` / `prompt` запрещены: они не знают про тему, блокируют
поток и не кликаются в тестах.

## 2. Кнопка без подписи — `IconButton` с `aria-label` **и** `title`

Оба поля обязательны на уровне типов, поэтому забыть их нельзя — `tsc` упадёт.
`aria-label` читает скринридер, `title` показывает браузер как тултип: одного
`aria-label` мало, мышью его не видно.

```tsx
<IconButton aria-label="Удалить задачу" title="Удалить задачу" onClick={remove}>
  ✕
</IconButton>
```

У кнопки с видимым текстом тултип не дублируй — только когда подписи одинаковые
и различает их лишь контекст.

## 3. Цвета — только из токенов

В новом правиле не должно быть хардкода цвета. Берём токены из `:root`:
`--bg`, `--panel`, `--surface`, `--text`, `--text-dim`, `--border`, `--border-soft`,
`--accent`, `--accent-fg`, `--accent-soft`, `--danger`, `--danger-fg`,
`--surface-hover`, `--ci-*` / `--ci-*-bg`. Геометрия — `--space-050/100/150` и
`--radius-medium`.

Не хватает токена — добавь его **и в `:root`, и в `[data-theme='dark']`**, а не
подставляй цвет в правило: иначе компонент выцветет в тёмной теме. Проверь
получившуюся пару в [Foundations/Colors](?path=/story/foundations-colors--contrast) —
контраст текста на фоне должен быть не ниже AA (4.5:1; для рамок и заливок 3:1).

Иконка рисуется `currentColor`, а не своим цветом — тогда она следует теме и
варианту кнопки. Прошитые цвета видно в [Foundations/Icons](?path=/story/foundations-icons--grid).

## 4. Разметка

- Своего оверлея и `position: fixed` у содержимого окна быть не должно — это дело `Dialog`.
- Всё, что рисует оверлей, регистрирует **один** слой через `useDialogStack`; свой слушатель Esc не вешаем.
- Мобильная вёрстка сразу: граница 720px, `useMediaQuery(MOBILE_QUERY)` — только если нужна **другая разметка**, а не другие стили.
- Растущие поля ввода — `useAutoGrow`.
- Данные и настройки — через стор, а не `fetch` из компонента; ошибка моста — тостом, а не тишиной.

## 5. Тесты и сториз

- Поведение — `*.dom.test.tsx` рядом с компонентом: клик → вызван мост → изменился экран. Экраны с тостом или подтверждением рендерим через `render` из `src/test/uiRender.tsx`.
- Сториз — `*.stories.tsx` рядом же. Для примитива полезна матрица «вариант × размер × состояние» в обеих темах (см. `UI/Button`); для экрана — минимальный случай и пара краевых.
- Тема в сториз бесплатна: переключатель в тулбаре меняет `data-theme` у корня и фон канвы. Если нужно сравнить темы на одном экране — рисуй два блока со своим `data-theme` (как `UI/Button` и `Foundations/CI Status`).
- Гейт: `npm run -w @voicechat/ui typecheck && npm run -w @voicechat/ui test`. Storybook в гейт не входит, но `*.stories.tsx` проверяются `tsc`, а `npm run -w @voicechat/ui build-storybook` — смоук-сборка витрины.
