# @voicechat/ui-foundation — общие инструменты UI

Общие CodeEditor/Monaco, ToolFrame/PopupFrame, DOM-утилиты и типизированный реестр
предпочтений. Здесь нет продуктовых экранов, host-store и импортов `@voicechat/ui`.
`test/` содержит общие fixtures и fake API, а не runtime-зависимость панели.

Общие реестры commands/useCommands/useHashRoute экспортируются через `runtime`:
панели получают их от host, иначе регистрация хоткеев попадёт в другой singleton.
Остальные чистые утилиты допускают включение в артефакт потребителя.
`styles.css` содержит общие редактор/окна; новые продуктовые стили — в продукте.
Изменение общего порта проверяет потребителей (`gate:app -- ui-foundation`);
пакет не является самостоятельным deploy-сервисом.
